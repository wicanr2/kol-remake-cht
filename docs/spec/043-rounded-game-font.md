## 玩家介面與狀態

- 工具列「畫面F10」開啟設定，提供「美術／字型」分頁。採定版原型的右側面板、顏色及比例。
- 字型頁兩個選項為「現有字型／粉圓柔邊」。預設現有字型，立即預覽並保存偏好。
  頁面保留「工具列目前已使用粉圓」與字距說明。既有EGA／HD選項仍可操作。
- 滑鼠及鍵盤皆可操作：左右鍵切分頁，上下／Tab移焦，Enter套用，Esc／右鍵返回。
  設定期間不推進遊戲；返回等待鍵鈕釋放。面板與命中區使用同一組960寬桌面座標，
  英文、收合工具列、EGA及HD縮放都沿同一換算。
- 舊偏好缺少字型欄時使用現有字型；另存現有`toolbar.json`的`game_font`欄位。
  僅接受`current`／`rounded`，不寫角色存檔，不保存戰鬥輔助啟用狀態。
  無法讀取時沿既有偏好錯誤處理；字模載入失敗保留目前字型並顯示原因。
- 英文模式保留原字模，字型偏好仍可選擇供之後中文模式使用。

## 字模與呈現契約

- Runtime只讀PNG及manifest，不載入TTF或系統字型。以固定TTF及原中文manifest產生兩套
  字模，16×18用於EGA、32×36用於HD；來源、產生器、輸出雜湊及缺字清單均記錄。
- 僅替換原中文字表已涵蓋的中文與全形標點，範圍U+2E80以上；英數字及其他符號沿原字模。
  粉圓缺字時沿原字模，不能使用方框代替。保留原始codepoint、字距、行高與量測結果。
- HD原生頁與比例文字標籤均套用粉圓，沿原安全矩形、截斷與色彩；不改輸入座標或角色數值。
  關閉選項即恢復原字模。工具列及設定頁繼續使用原有粉圓20像素字模。
- PNG字模編入程式，來源及OFL沿既有字型授權保存，不加入原始TTF。公開引擎與純EGA包
  不依賴HD圖庫即可切換字型。未核准重建既有六包、重新錄影或新增Release。

## 驗收與停止線

1. 字模來源及輸出可重生，字寬不變，粉圓缺字沿原字模；移除替代字型後像素復原。
2. 實際GUI在EGA與HD切換字型、分頁及美術模式，觀察文字變化與介面不裁切。
3. 滑鼠／鍵盤操作、暫停及釋放閘門、收合工具列、英文模式與新程序偏好重載。
4. 正常建立／招募角色、住宿保存及重載，字型切換不改角色資料；抽樣人物頁或商店文字。
5. README附正式設定截圖、入口、保存方式及已交付版本界線。
