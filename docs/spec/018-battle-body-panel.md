# SPEC-018：戰鬥左下人形與疲勞框

狀態：**CONFORMED**（2026-09-30：原版正常戰鬥受傷後同一刻的人形、傷勢遮罩與疲勞直條與 remake 一致，見 `docs/verification/battle-panels-20260930.md`）；2026-09-08 由同日 DRAFT 經下列證據審查升 READY。範圍為原版既有資訊的缺漏接線，不變更規則或操作決策。

## 證據

輸入 `KOLTOWN-unpacked.EXE` SHA-256
`01f6f9a95c4adf8e9da59fa83bae57aa282e5576767b41bfc2f23302aeb9d1d2`，
IDA Pro 9.4、IDA linear 位址；原版遮罩與直條由 dosgolem 自行執行。
詳見 `docs/re/20260908-battle-panels.md`、`docs/re/20260908-body-overlay.md`。

## 資料與顯示契約

1. 正式 runtime 只讀已驗證 PNG。男性／女性／敵人人形使用 MISCPICS 3／4／5，
   三張均為 56×70；放在原版 320×200 畫布的 (72,85)。
2. 六部位當前值取 Actor 傷肢欄，最大值沿用 `Parts(Threshold)`，與現有扣傷／治療路徑一致。
   超過 127 的原始當前值視為零；最大值必須為正，非法資料回報錯誤，不偷偷除零或猜補。
3. 依逆向矩形及分段整數截斷計算各部位遮罩，只將 EGA 7、8、15 轉為 12，保留其餘像素。
   不修改素材快取，角色之間不得共用可變傷勢圖。
4. 疲勞條分界 `clamp(84+(100-((2*S-F)/2)*100/S)*72/100,84,155)`。
   每個除法按原版順序截斷，`2*S-F` 先保留原版 16-bit signed 中間值。
   體力 S 必須為正。兩個填色矩形均含端點，後畫的藍色覆蓋共同分界列。
5. `BeginTurn` 顯示行動者；進入選目標先清空，再依初始格是否有人顯示。
   移動目標游標同步資訊；離開人物到空格清空。進入招式與防禦選單保留被檢視者，
   返回主選單重新顯示行動者。輪末問題及執行段清空；例外是執行段中效果 6 的法術問部位
   那一頁，框裡畫目標的人形與傷勢，不畫疲勞直條（RE-153，SPEC-012）。
6. 顯示角色的選擇不得改動行動者、亂數或正式指令。依戰場目前可見人物選取，
   不透過牆顯示不可見人物資訊。原版 `sub_24131:0x24304..0x24316` 的初始格檢查、
   `0x24639..0x246DD` 的人物辨識與 `0x246EC..0x24730` 的空格清除為依據。
7. 左下框的指令／招式／防禦圖示另待完整規格，不因本項通過而宣稱整個 A10 完成。
   左上模式切換及中文資料頁亦不在此規格的完成聲明內。

## READY 證據審查

`TestBattleBodySpriteOriginal` 已由原版 `sub_1103F` 確認三次快取路由為 3／4／5，
目的 byte 欄 9..16、列 85..155。初始化格式字串為 `misc%s.0`，模式字串表依序為
`pics、pcga、herc`；現有 EGA 素材探針 `docs/re/miscpics-ega-visual-probe.json`
獨立記錄 request code 0x47..0x49 與同樣三張圖的索引、56×70 尺寸及雜湊。
三張 PNG 已人工檢視為男性、女性、敵人人形，manifest 雜湊一致。

顯示選擇由 IDA 資料流確認：`0x1F178` 畫目前規劃者；`0x24316` 在初始格有人時
直接進入目標繪製；`0x2467F／0x24696` 暫設被檢視索引；`0x248EF..0x248F2`
只恢復行動索引，沒有重畫框。`0x1F6BA..0x1F70F` 進招式選單也不重畫。
輪末 `0x1FB04／0x1FB20` 清空兩框再問下一輪。這些為原始程式控制流證據，
不是以 remake 測試反推原版語意。身體／直條合法輸入邊界由既有 156 組案例確認。
