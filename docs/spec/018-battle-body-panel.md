## 資料與顯示契約

1. 正式 runtime 只讀已驗證 PNG。男性／女性／敵人人形使用 MISCPICS 3／4／5，
   三張均為 56×70；放在原版 320×200 畫布的 (72,85)。
2. 六部位當前值取 Actor 傷肢欄，最大值沿用 `Parts(Threshold)`，與現有扣傷／治療路徑一致。
   超過 127 的原始當前值視為零；最大值必須為正，非法資料回報錯誤，不偷偷除零或猜補。
3. 依逆向矩形及分段整數截斷計算各部位遮罩，只將 EGA 7、8、15 轉為 12，保留其餘像素。
   不修改素材快取，角色之間不得共用可變傷勢圖。
4. 疲勞條分界 `clamp(84+(100-((2*S-F)/2)*100/S)*72/100,84,155)`。
   每個除法按原版順序截斷，`2*S-F` 先保留原版 16-bit signed 中間值。
   體力 S 必須為正。兩個填色矩形均含端點，後畫的藍色覆蓋共同分界列。
5. `BeginTurn` 顯示行動者；進入選目標先清空，再依初始格是否有人顯示。
   移動目標游標同步資訊；離開人物到空格清空。進入招式與防禦選單保留被檢視者，
   返回主選單重新顯示行動者。輪末問題及執行段清空。
6. 顯示角色的選擇不得改動行動者、亂數或正式指令。依戰場目前可見人物選取，
   不透過牆顯示不可見人物資訊。原版 `sub_24131:0x24304..0x24316` 的初始格檢查、
   `0x24639..0x246DD` 的人物辨識與 `0x246EC..0x24730` 的空格清除為依據。
7. 左下框的指令／招式／防禦圖示另待完整規格，不因本項通過而宣稱整個 A10 完成。
   左上模式切換及中文資料頁亦不在此規格的完成聲明內。
