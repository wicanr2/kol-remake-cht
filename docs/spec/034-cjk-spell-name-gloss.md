# SPEC-034：法術名的中文注解

狀態：**CONFORMED**（2026-09-25，音節規則與 48 筆法術記錄交叉驗證完成；位置經使用者以原型確認；正常按鍵畫格收據齊全）。
法術名保留精靈語原文，只在中文畫面加注解；不改法術資料、法術編輯器輸入、存檔或英文畫面。

## 證據

- 說明書印刷頁 72–75（[第 7 章「施放法術」](../manual/chapters/07-advanced-gamers.md)）：法術名依序由
  「種族＋屬性＋強度＋距離＋（持續時間）＋亞種」的音節組成，並附六個範例。
  `knightslegend-manual.pdf` SHA-256
  `4c80f5d4c7221f9d3376546d249d52e2fc7fc0f73b48ee9daf6e20ce87d7086a`。
- 音節表放在 [`docs/i18n/spell-words-zh-Hant.json`](../i18n/spell-words-zh-Hant.json)，中文詞取自已校對的
  說明書譯文；種族、屬性、亞種索引與 MAGIC.0 的 class／stat／subclass（RE-128）相同。
- 交叉驗證（已證實）：說明書六個範例全部唯一解析，結果與範例說明相符；
  `town-buildings.json`（SHA-256 `a9ffa28a…c5e754`）裡 48 筆商店法術全部唯一解析，
  種族／屬性／亞種與法術記錄 `guards[0]` 高低 nibble、`effect` 逐筆一致，0 筆不符。
  測試：`internal/magic/word_test.go`。
- 差異：說明書要求四個人形種族以 `TA` 結尾，遊戲資料省略（如 `Tyanalon`），兩種都接受。
  MAGIC.0 把火蜥蜴拼成 `Salamandar`，顯示譯名表另列一筆。

## 契約

1. 法術名本身不翻譯。它就是法術的構成規則，玩家在法術編輯器輸入的也是這些詞，
   與必須輸入的原作關鍵字同類。
2. 只有唯一解析成功的名字才加注解；玩家自取、拆不開或有歧義的名字不加，不猜。
3. 注解格式：`種族・屬性・強度・距離[・持續X]`；有亞種時以亞種的顯示譯名（SPEC-033）
   取代種族，例如 `布洛姆・疲勞・中等・遠距離`。正負效果不在名字裡，不寫進注解。
4. 位置（使用者 2026-09-25 以原型確認）：
   - 城鎮法術店與「修改法術」清單：選中那一列的名字後面，同一行、未選取的顏色，
     放不下就截斷，不蓋捲動箭頭。
   - 戰鬥「哪一個法術？」：規劃段底部訊息區畫卷軸，兩行寫「法術名：」與注解。
     正負效果那一頁的列解析不出來，不畫。
5. 英文模式（對拍）完全不變。
