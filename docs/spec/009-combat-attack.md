# SPEC-009：戰鬥的攻擊結算

狀態：**近戰（指令 0x21 武器／0x29 徒手）READY；射擊、法術與敵人 AI DRAFT**  
是否授權實作：本規格列出的攻擊值、防禦值、命中判定、傷害與部位**是**（僅限規則層，
不含 UI 與敵人 AI）；射擊（0x23）、法術與 `sub_2374C` 的敵人 AI**否**。

## 範圍

本規格定義一次近戰攻擊從攻擊值算到傷害落到部位為止的每一步。證據入口是
`docs/re/RESEARCH-LOG.md` 的 RE-080（`sub_26AC2`、`sub_24FD3`、`sub_26D76`、
`sub_277F4` 與七張 DGROUP 表），物品記錄的版面沿用 RE-075。

**驗證限制**：這一份沒有同狀態收據。原版每一步都擲骰（攻擊值、防禦值、傷害骰、
部位），而原版的亂數狀態不可重建，因此只能以逐條對碼與單元測試支撐；
實作標為 READY 但**不標 CONFORMED**，等能重播原版亂數或找到可觀察的不變量再說。

## 原版行為契約

### 1. 武器數字（`sub_26AC2`）

隊員手上的武器識別是角色記錄 +0x3D。拿它比對四列武器技能（+0x52 + 13 × 列），
對到就把那一列的攻擊技能讀成 `攻擊技能`、防禦技能讀成 `招架技能`。武器欄在
角色記錄 +0x30（徒手是 +0x100 + `[0x0FD2 + 選項]`，射擊是 +0x70），欄位版面同
RE-075 的物品記錄：`+0x08` 高 nibble 是基礎傷害、`+0x0A` 重量、`+0x0B` 耐久、
`+0x0C` 傷害碼、`+0x0D` 種類、`+0x0E` 低 nibble 等級、`+0x0F` 旗標。

### 2. 負重與盾牌（`sub_24FD3`）

```
係數 = 70 − (等級 − 1) × 5
重量 = 武器重量；武器速度 = 重量 × 係數 ÷ 100
重量 = 重量 ÷ 2 ＋ 三件護甲的重量
盾牌存在、兩隻手臂都還在、武器不是雙手時：盾牌等級 = 盾牌 +0x0E 的低四位；重量 += 盾牌重量
負重 = 係數 × 重量 ÷ 100
```

### 3. 攻擊值與攻擊分數（`sub_26D76`）

```
攻擊值 = 力量 + 攻擊技能
傷勢 = 50 × 累積傷害 ÷ 昏迷門檻
攻擊值 −= 攻擊值 × 傷勢 ÷ 200 + 累積傷害 × 10 + 挨打累計 × 20 + 負重
攻擊分數 = 攻擊值 ÷ 10 + rand(100)
列 = (攻擊選項 == 1) ? rand(3) − 1 : 攻擊選項 + 1
攻擊分數 += [0x110A + 14 × 列 + 2 × 對手的防禦選項]        ; 16-bit 有號
若攻擊分數 ≥ 0 且攻擊選項 > 1 且 (武器種類 & [0x109C + 攻擊選項 − 2]) == 0：攻擊分數 ÷= 2
```

### 4. 防禦值與防禦分數

```
防禦值 = 招架技能 ÷ 這一回合已招架次數 + 快捷
防禦值 −= 防禦值 × 傷勢 ÷ 200 + 累積傷害 × 10 + 負重
若有盾牌：防禦值 += 100 × 盾牌等級 + 200
防禦分數 = 防禦值 ÷ 10 + rand(100)
對手的防禦選項為 0（不招架）時防禦分數直接為 0
```

### 5. 命中判定

- 攻擊分數 < 0：落空。差 30 以上印記錄 0x13B、10 以上 0x13C、其餘 0x13D。
- 攻擊分數 ≥ 防禦分數：命中，印記錄 0x13E。
- 否則被擋下：查 `[0x11B2 + 11 × 防禦選項 + 攻擊選項]` 取記錄 0x14F…0x158。

### 6. 傷害與部位

```
骰數 = 傷害碼 ÷ 32 + 1
骰面 = [0x00D4 + ((傷害碼 ÷ 4) & 7)]                ; 02 03 05 07 09 0B 13 63
力量加成 = ((力量 − 70) ÷ 8) × (70 − 傷勢) ÷ 100
傷害 = 基礎傷害 + Σ rand(骰面) + 力量加成 + [0x1200 + 攻擊選項]
傷害 += [0x120C + (攻擊分數 − 防禦分數) ÷ 20]        ; 餘裕為負就不加
上限 = 骰數 × 骰面 + 1 + 基礎傷害；超過上限就扣裝備耐久後夾回上限
傷害為負夾成 0
部位：擲 rand(100)，在 `[0x121C + 6 × 列]` 的累積機率裡找第一個 ≥ 的位置，
      列 = [0x122E + 攻擊選項]
```

### 7. 落到身上（`sub_277F4`）

```
累積傷害 += 傷害（上限 0x7F）；累積傷害 ≥ 昏迷門檻就把頭與胸設成 0xFF（倒下）
部位血量[部位] −= 傷害；扣到 0 以下設 0xFF（那一肢廢掉）
對手的挨打累計 += 傷害
```

訊息：0x140「The」＋ 0x141/0x142 ＋ 0x143 ＋ 0x144 + 部位，再依結果接 0x14A…0x158。
