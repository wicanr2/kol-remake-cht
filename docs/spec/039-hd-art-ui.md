# SPEC-039：HD 手繪美術與介面工作計畫

狀態：**DRAFT**。不授權正式替換素材、版面或保存格式。

本計畫接續使用者已選定的手繪方向。素材母體與程式依賴沿用
[RE-229](../re/20261004-hd-art-ui-prototype.md) 與
[RE-294](../re/20261006-hd-render-dependencies.md)，不重新開啟已完成的 EGA 解碼。
目前 EGA 版仍是可遊玩基準；HD 原型另行比較。

## 已知條件與第一個決策

現行五份 manifest 共 804 張 PNG、43 個圖組。包括 748 張圖片、11 張顯示圖集、
3 張字型圖集、36 張渲染或地圖資料及 6 張結構遮罩。這個數目是輸入母體，
不代表每張都應手繪。資料與遮罩必須保留其規則用途。

手繪媒材已確認，人物造型、構圖及正式素材契約尚未確認。
既有方向板實際為 1122×1402，只供比較，不作正式 HD 資產。
解析度的可丟棄原型見 [比例及版面比較](../../workplace/hd-art-ui-20261004/layout-review.html)。
使用者於 2026-10-11 選定 A：1920×1200，保持原比例。此決定不包含尚未展示的造型或素材契約。
[決策記錄](../verification/cjk-closeout-20261011/hd-decision.json)保存原型雜湊與核准範圍。

| 選項 | 呈現 | 影響 |
|---|---|---|
| A，1920×1200 | 保持原比例；1080p 顯示器以 1728×1080 置中 | 左右各留 96 像素，可沿用相對位置 |
| B，1920×1080 | 側欄、主視野及操作列分別等比縮放、重新安排 | 需重新確認文字安全矩形、留白與滑鼠命中區 |

後續以 A 製作第一批原型，集中確認美術與可讀性，不增加可見地圖範圍。
B 保留為比較記錄。正式文字矩形與命中區仍須在可操作原型核對。

## 執行順序與閘門

| 階段 | 具體工作 | 完成條件 |
|---|---|---|
| 1，版面 | 比較正常城鎮及戰鬥的 A／B 畫面，標出最長中文字、六人列與操作區 | 使用者選定解析度與版面，記錄原型與決策 |
| 2，素材契約 | 逐組定尺寸、透明色、錨點、圖層順序、圖集切格及動畫幀；核對現行載入器 | 先做城鎮門面、六人肖像與戰鬥人形的可丟棄原型；證據審查後升 READY |
| 3，最小完整切片 | 從正常入口走過旅店、城鎮、遭遇、戰鬥及住宿重載，接入同一批試作素材 | 英文／繁中規則狀態相同；中文無缺字或裁切；滑鼠結果等價；既有 v3 可讀 |
| 4，分批繪製 | 按下表交付；每批含 PNG、來源／權利分類、雜湊及疊圖接觸表 | 尺寸與格式檢查、目視核對、正常玩家畫格均通過，再接下一批 |
| 5，跨平台與交付 | 檢查 Linux、Windows、macOS 的縮放、字體、輸入與封包 | 依實際測過的平台聲明結果；另定新版號與打包，不覆寫現行交付 |

第一個可評審成果應是「旅店門面、六人肖像、戰鬥規劃」三張可操作原型，
附同一正常路徑的 EGA 對照。整頁美術方向板不能代替這個閘門。

## 必須先解決的相依關係

- 戰鬥人形目前 56×70，傷勢按像素著色。HD 圖與部位遮罩要一起驗，不能只放大貼圖。
- 天候目前 64×62；隊伍標記使用 16×160 圖集；地圖以 16×16 切格。
  顯示尺寸與規則格子必須分開處理，避免改動通行及選格結果。
- 自訂肖像與盾牌目前 40×38，會由 v3 存檔覆蓋。HD 如何顯示舊自訂圖與編輯結果，
  需先展示原型並確認，不能默默更改保存格式。
- 人物有多層組合裝備，必須驗穿戴、手持、受傷及空格回退，不能只驗一張成品。
- runtime 繼續讀 PNG 與 Ogg Vorbis。素材重繪不自動取得原作的公開散布權；
  沿專案權利分類另作核對。

規則來源、亂數、任務、戰鬥節奏與保存政策沿目前規格。若 HD 實作需要改變其中任何一項，
先拆成獨立 DRAFT 並交由使用者決定。本計畫升 READY 前不進正式玩家路徑。
