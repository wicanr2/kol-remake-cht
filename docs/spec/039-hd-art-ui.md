## 必須先解決的相依關係

- 戰鬥人形目前 56×70，傷勢按像素著色。HD 圖與部位遮罩要一起驗，不能只放大貼圖。
- 天候目前 64×62；隊伍標記使用 16×160 圖集；地圖以 16×16 切格。
  顯示尺寸與規則格子必須分開處理，避免改動通行及選格結果。
- 自訂肖像與盾牌目前 40×38，會由 v3 存檔覆蓋。HD 如何顯示舊自訂圖與編輯結果，
  需先展示原型並確認，不能默默更改保存格式。
- 人物有多層組合裝備，必須驗穿戴、手持、受傷及空格回退，不能只驗一張成品。
- runtime 繼續讀 PNG 與 Ogg Vorbis。素材重繪不自動取得原作的公開散布權；
  沿專案權利分類另作核對。

規則來源、亂數、任務、戰鬥節奏與保存政策沿目前規格。若 HD 實作需要改變其中任何一項，
先拆成獨立 DRAFT 並交由使用者決定。其他批次升 READY 前不進正式玩家路徑。

## HD圖片取樣的跨平台數值一致性

狀態：有限 **CONFORMED**。使用者維持HD逐通道最多一色階，並暫緩新版發布。這是已核准圖片的精度修正，不新增造型、操作或正式規則；實作前先升READY。

[交付診斷](../verification/release-v1.0.2-20261013.md)已證實同一Linux程式在Mesa22.3.6與25.2.8間有兩色階差；相同Mesa環境的Linux／Windows則在一色階內。差異位於雙線性縮放的肖像及旅店頭像。驅動實作是強推論，未追查每個驅動的內部捨入指令。

- 圖片保持原檔、來源指紋、畫面位置與尺寸；只將`drawHD`的雙線性取樣改為固定整數運算。
- 目的像素中心對應來源像素中心。每軸使用有理數權重，四鄰點以64位整數加權，最後一次四捨五入；邊界夾到來源最外像素。RGBA沿用預乘透明度。
