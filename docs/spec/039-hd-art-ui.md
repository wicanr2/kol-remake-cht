狀態：整體 **DRAFT**；下方「首批接入契約」為有限 **CONFORMED**，只涵蓋其列出的呈現範圍。

本計畫接續使用者已選定的手繪方向。素材母體與程式依賴沿用
[RE-229](../re/20261004-hd-art-ui-prototype.md) 與
[RE-294](../re/20261006-hd-render-dependencies.md)，不重新開啟已完成的 EGA 解碼。
目前 EGA 版仍是可遊玩基準；首批 HD 已接入遊戲，入口為[實際場景驗收](../verification/hd-runtime-20261011.md)。
[旅店、六人肖像與戰鬥比較原型](../verification/hd-first-slice-20261011/review.html)保存核准樣張。

[SPEC-040](040-controlled-scene-acceptance.md)的受控場景門檻。

## 已知條件與第一個決策

現行五份 manifest 共 804 張 PNG、43 個圖組。包括 748 張圖片、11 張顯示圖集、
3 張字型圖集、36 張渲染或地圖資料及 6 張結構遮罩。這個數目是輸入母體，
不代表每張都應手繪。資料與遮罩必須保留其規則用途。

手繪媒材、首批造型與下方素材契約已確認，其他批次的造型與分層契約維持 DRAFT。
既有方向板實際為 1122×1402，只供比較，不作正式 HD 資產。
解析度的可丟棄原型見 [比例及版面比較](../../workplace/hd-art-ui-20261004/layout-review.html)。
使用者於 2026-10-11 選定 A：1920×1200，保持原比例。此決定不包含尚未展示的造型或素材契約。
[決策記錄](../verification/cjk-closeout-20261011/hd-decision.json)保存原型雜湊與核准範圍。

| 選項 | 呈現 | 影響 |
|---|---|---|
| A，1920×1200 | 保持原比例；1080p 顯示器以 1728×1080 置中 | 左右各留 96 像素，可沿用相對位置 |
| B，1920×1080 | 側欄、主視野及操作列分別等比縮放、重新安排 | 需重新確認文字安全矩形、留白與滑鼠命中區 |

後續以 A 製作第一批原型，集中確認美術與可讀性，不增加可見地圖範圍。
B 保留為比較記錄。正式文字矩形與命中區仍須在可操作原型核對。

## 執行順序與閘門

| 階段 | 具體工作 | 完成條件 |
|---|---|---|
| 1，版面 | 比較正常城鎮及戰鬥的 A／B 畫面，標出最長中文字、六人列與操作區 | 使用者選定解析度與版面，記錄原型與決策 |
| 2，素材契約 | 逐組定尺寸、透明色、錨點、圖層順序、圖集切格及動畫幀；核對現行載入器 | 先做城鎮門面、六人肖像與戰鬥人形的可丟棄原型；證據審查後升 READY |
| 3，最小完整切片 | 用受控輸入抵達旅店、城鎮、遭遇與戰鬥，接入同一批試作素材 | 對應場景與中文畫面正確；滑鼠命中可用；既有 v3 可讀 |
| 4，分批繪製 | 按下表交付；每批含 PNG、來源／權利分類、雜湊及疊圖接觸表 | 尺寸與格式檢查、目視核對、對應場景畫格均通過，再接下一批 |
| 5，跨平台與交付 | 檢查 Linux、Windows、macOS 的縮放、字體、輸入與封包 | 依實際測過的平台聲明結果；另定新版號與打包，不覆寫現行交付 |

第一個可評審成果為「旅店門面、六人肖像、戰鬥規劃」三個可操作原型，
附來源場景的 EGA 對照。整頁美術方向板不能代替正式素材及傷勢遮罩驗證。

## 必須先解決的相依關係

- 戰鬥人形目前 56×70，傷勢按像素著色。HD 圖與部位遮罩要一起驗，不能只放大貼圖。
- 天候目前 64×62；隊伍標記使用 16×160 圖集；地圖以 16×16 切格。
  顯示尺寸與規則格子必須分開處理，避免改動通行及選格結果。
- 自訂肖像與盾牌目前 40×38，會由 v3 存檔覆蓋。HD 如何顯示舊自訂圖與編輯結果，
  需先展示原型並確認，不能默默更改保存格式。
- 人物有多層組合裝備，必須驗穿戴、手持、受傷及空格回退，不能只驗一張成品。
- runtime 繼續讀 PNG 與 Ogg Vorbis。素材重繪不自動取得原作的公開散布權；
  沿專案權利分類另作核對。

規則來源、亂數、任務、戰鬥節奏與保存政策沿目前規格。若 HD 實作需要改變其中任何一項，
先拆成獨立 DRAFT 並交由使用者決定。其他批次升 READY 前不進正式玩家路徑。

## 首批接入契約

狀態：有限 **CONFORMED**。使用者於 2026-10-11 回覆「同意囉，開始吧」，核准前述首批原型。
實作前審查為 READY；實作後依下列契約完成受控場景、正常保存及實際滑鼠驗收。
依據為[已保存原型](../verification/hd-first-slice-20261011/review.html)、其 manifest 與完整生成提示。
這項確認涵蓋目前門面及六人造型；其他批次、傷勢遮罩及組合裝備仍維持 DRAFT。
首位手臂及盾牌採核准圖現況，不另生成變體；1774×887 門面保留原尺寸，顯示縮至1152×576。

| 項目 | 契約 |
|---|---|
| 入口 | `-graphics hd` 選用首批；預設 `ega`，僅繁中可啟用 HD；`-hd-assets assets/hd/first-slice` 指定素材包 |
| 畫布 | 規則與文字仍畫在960×600；最後呈現1920×1200，原畫最近鄰乘二，手繪圖片線性縮放 |
| 素材包 | `assets/hd/first-slice/manifest.json`；兩張核准 PNG 原樣保存，尺寸1774×887及1536×1024，人物圖集3×2，每格512×512 |
| 對應方式 | 對原門面192×96、角色40×38的RGB像素取SHA-256，匹配才換；對應鍵只用圖像指紋，姓名與隊伍位置不作辨識鍵 |
| 城鎮 | 門面只替換相同圖像；旅店及戶外六人格以真實隊員逐一匹配；資料頁沿現行可見隊員清單，法術編輯整頁不加人物 |
| 戰鬥 | 只在非怪物、非裝備清單的人物資訊框換匹配立繪；地圖、傷勢人形、六格指令與文字保留 |
| 回退 | 未匹配人物、自訂肖像、其他門面及未繪畫面保留原圖；自訂圖若與原圖像素相同可匹配，不改原保存內容 |
| 載入 | 一次驗全部PNG的雜湊、實際尺寸、六個不同人物指紋與來源；缺件、錯誤或尺寸越界在開始遊戲前拒絕，不使用部分素材包 |
| 輸入 | Ebitengine回報的1920×1200座標先除二，再走原命中區；編輯器之後照原契約再除三；右鍵、滾輪與鍵盤保持 |
| 保存 | HD選項只控制本次呈現，不寫入v3；舊自訂圖及讀檔沿原流程 |

畫面位置沿核准原型，姓名區、文字、外框與操作列不得被手繪圖片覆蓋。
現行版面與圖片消費端由RE-294及本輪程式讀取已證實；RGB指紋只證明圖片對應，不宣稱裝備層次已HD化。
驗收採SPEC-040：旅店門面、真實六人、戰鬥資訊框、書本至城鎮及舊v3重載；
兩種呈現的同輸入trace與保存相同，正式EGA圖保持，滑鼠換算及素材損壞負例通過。
本輪實作與收據入口為[首批HD接入](../verification/hd-runtime-20261011.md)。
八條路徑各98個EGA／HD狀態與中文紀錄相同；65張EGA與修改前相同。
實際住宿保存除saved_at相同；舊v3、自訂肖像回退、原尺寸及縮小視窗點選均通過。
人物裝備組合、傷勢遮罩、其他美術與三平台封包依原批次繼續，不以本切片宣稱整體HD完成。
