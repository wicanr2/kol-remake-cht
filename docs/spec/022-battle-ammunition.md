# SPEC-022：隊員射擊彈藥消耗

狀態：READY（2026-09-08，同日 DRAFT 經下列證據審查）。

## 證據與範圍

輸入 `KOLTOWN-unpacked.EXE`，SHA-256
`01f6f9a95c4adf8e9da59fa83bae57aa282e5576767b41bfc2f23302aeb9d1d2`。
工具 IDA Pro 9.4，位址為 IDA linear，DGROUP 基底 `0x2DED0`。
保留原始函式 `sub_1E3A8` 及運算元 `[bx+6712h]`；以下語意為已證實。

- `0x1E78D`／`0x1E921`：隊員初始化該位元組為 `0x13`，不是怪物種類。
- `0x2082C..0x20880`：射擊結算後，武器種類 6、10、11 保留裝填及指令；
  其他種類清除 `+0x1D` 裝填，將 `+0x25` 指令改回 `0x22`。
- `0x20884..0x208CE`：首位元組減一；原值零改為 `0xFF` 並清除指令。
- `sub_228B7:0x22996..0x229AD`：該值為 `0xFF` 不提供射擊／裝填選項。
- `sub_22EFC:0x231AE..0x231D1`：該值為 `0xFF` 顯示零，其他值加一。
  顯示標頭、字型及座標仍另行驗收，本規格先修正式消耗。

新版 dosgolem 的 `TestBattleAmmunitionConsumeOriginal` 在原函式段內建立有界堆疊，
執行 `0x2082C..0x208CE` 的真實指令：首末隊員、五種武器、255 個有效原值，
共 2,550 組通過。`TestBattleAmmunitionPanelOriginal` 的 128 組標頭／數字比較通過。
收據 `workplace/ammunition-20260908/manifest.json`；這是有界常式證據，不是正常戰鬥。

## 正式契約

1. 維持現有 Actor.Kind 儲存對應原始首位元組，補明「隊員為剩餘發數減一，
   敵人為怪物索引」；不更改資料格式或敵人肖像。
2. 裝填不消耗。隊員真正射出一發後消耗一次，包含射空、遭牆／樹擋住與命中人物。
   消耗不呼叫亂數；不得只在命中時扣除。
3. 需要裝填的武器射後回到未裝填指令。最後一發後清除指令，原有指令列隱藏
   射擊／裝填。既有戰鬥起始值 `0x13` 對應二十發。
4. 此資料是每場戰鬥初始化的狀態；不自行新增跨戰鬥彈藥庫存或存檔欄位。
5. 不把敵人的 Kind 當彈藥扣除；敵方射擊路徑不在本次隊員證據範圍內。

## 驗收

完整射擊函式測試涵蓋裝填不扣、射空扣除及最後一發；正式消耗函式直接與
2,550 組原版結果比較。正常玩家射擊與彈藥資訊框仍待驗證，未達 CONFORMED。

READY 審查：初始化、消耗寫入、耗盡選單與數字讀取均有原始定位，原版有界測試
通過；原版射擊呼叫 `sub_26D76(0)` 返回後無條件進入扣除段，故消耗不依命中。
保留既有資料表示，修復不需選擇新規則；未擴張敵人、持久庫存或畫面驗收聲明。

## 彈藥資訊框增補（READY，2026-09-08，同日 DRAFT 審查通過）

原版 `sub_22EFC:0x2311D..0x231D1`：僅隊員裝備模式，手上物品非空、
物品 +0x0C bit0 非零、+0x0D 高三位為零時顯示。種類 0x12／0x16 印 BOLTS:，
其他符合條件者印 ARROWS:；數字讀被檢視隊員的當前首位元組，按上述規則換算。
沿用 Member.HasWeapon、Weapon.Code／Kind 與 Actor.Kind，不新增來源欄位。

KOLDATA 記錄 0x101 模板六次換行後，0x102／0x103 標頭承接 (24,60)，
word_2DF54=1 使用既有小字型，緊接十進位數字，無額外空格。
新版 dosgolem `TestBattleAmmunitionTextOriginal` 執行真實模板、標頭與數字流程，
ARROWS／BOLTS 各測原值 0／19／255，共六組通過；只替換字元出口，未驗像素字寬。
來源為 `assets/original-derived-data/ui-text.json` KOLDATA 257..259 的原始控制碼，
可回查該檔來源雜湊與 RE-063／067；本機收據 `workplace/ammunition-text-20260908`。

顯示是唯讀，不重擲、不重設彈藥。切至肖像、空目標、敵人或換成近戰／空手應不顯示。
UI 仍限於既有 119×73 安全區，最長有效文字 ARROWS:255 可完整容納。
本增補替代 SPEC-019 第六項的彈藥待查限制；正常 GUI 與原版同狀態驗收仍未完成。

審查結果：128 組顯示閘門與數字、六組真實文字流程及既有可變物品接線足以實作。
僅補原版已有資訊，沿用既有小字型；未變更操作方式、資料格式或中文排版決策。

實作驗收更新：正式資訊框 128 組原版比較與完整測試／建置通過。
正常 GUI 150 個輸入確認 Olear 的 Elf Bow 從 20 發射至 19 發；弩與耗盡的正常 GUI
及 dosgolem 整場同狀態仍未完成，保持 READY。見 `docs/verification/ammunition-panel-20260908.md`。
