# SPEC-040：受控場景與中文畫面驗收

狀態：**CONFORMED**。限已登記場景與驗收工具，見[收據](../verification/controlled-scenes-20261011.md)。
依使用者 2026-10-11 的明確決定採用，取代目前收尾的正常長流程與嚴格對拍門檻。

使用者允許鎖定生命值、提高攻擊及準備對應場景。重製版抵達指定畫面，確認中文有顯示、
內容及畫面正確，即通過該場景。歷史原版對拍保留原有證據等級，不再阻擋 HD 開工。

## 驗收工具

使用 `go build -tags sceneverify -o <驗收程式> ./cmd/kol` 建置獨立程式。
正式建置不帶這個標籤，不接受以下參數，也不包含驗收設定。

| 參數 | 行為 |
|---|---|
| `-verify-scenes` | 宣告本次為受控場景驗收 |
| `-verify-lock-hp` | 隊員部位與累積傷害不減少；敵人維持正常受傷 |
| `-verify-attack 20` | 隊員命中後、護甲吸收後的近戰與射擊傷害乘 20；不改命中、移動、敵人傷害及法術威力 |
| `-verify-world-start 48,9` | 準備世界落點，再呼叫現行到達回呼與問答流程；不直接設定勝利或結局 |

輔助模式必須指定 play／flow 場景、輸入腳本、狀態軌跡與截圖，且禁止 `-save`。
倍率允許 1…100，預設 1，鎖血預設關閉。軌跡逐步記錄輔助條件及 `original_parity_claimed: false`。
替代存檔與場景資料只寫驗收工作區，保存原始及替代輸入雜湊與變更說明。
正式武器、角色、typed data、保存格式與既有交付包不隨本模式修改。

## 預先登記的畫面與判準

| 組別 | 目標 |
|---|---|
| 書本與建角 | 封面、中文目錄、角色選項、名冊、刪除、港務、建角屬性及肖像 |
| 城鎮與資料 | 旅店、七城建築、中文住宅告示、人物／物品／隊伍頁，商店、訓練、馬廄及法術服務 |
| 世界與任務 | 世界地圖、城門、野外提示、接任務與任務清單 |
| 戰鬥及結尾 | 遭遇、規劃、執行訊息、勝利／戰利品及結局段落 |

每個場景必須實際繪製 PNG，留下場景或狀態定位，確認中文可辨讀、無缺字或明顯裁切，
主要圖像、面板與操作列符合對應場景。文字檢查與接觸表輔助目視，不能以工具退出 0 取代畫面確認。
無法抵達或畫面有問題的項目保持失敗／未驗，不因降低門檻自動通過。
先前已確認的固定畫面可重用，記錄來源及程式差異；新增輔助模式集中補戰鬥至結局與缺輸入的服務畫面。

通過聲明只限已列出並檢查的場景，不宣稱所有亂數分支、正常流程可達或原版整場一致。
HD 試作採同一場景判準；正式 HD 造型與素材契約仍依 [SPEC-039](039-hd-art-ui.md)評審。

## 中文結局修正子契約

狀態：CONFORMED。七張結局圖與各筆 ENDTXT 的既有定位共用 `book.CJKScale`，
繁中圖框、圖片與文字座標都乘三，字模維持 16×18。英文保留原座標、原字模與原圖片尺寸。
本修正只解決已觀測的重疊，不改文字內容、結局條件、段落順序與按鍵等待。
第四段繁中 ENDTXT[7] 的末段以 `~V96~H01`、第六段 ENDTXT[12] 以 `~V98~H01` 定位到圖片下方。
中文行數比英文少，不能只靠 `~H01` 回到左欄而沿用目前行號。
`internal/ui/ending_cjk_test.go` 使用七段真實譯文及字模檢查畫布、圖框及文字互疊。

驗收入口：[受控場景收據](../verification/controlled-scenes-20261011.md)。
