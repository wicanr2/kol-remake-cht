# SPEC-012：施法

狀態：**READY**（效果 5 的疲勞鏈、效果 7／8 的欄位與選部位的互動除外）  
證據：RE-100（`sub_2818D` 逐條）、RE-093（指令碼 `0x0D` 的分派）、RE-067（`0x1A0` 那個旗標）  
授權實作：擲骰、擋招、效果、倒數、資料抽取與兩張清單**是**；效果 5 的疲勞鏈、
效果 7／8 的欄位與選部位的互動**否**

## 1. 法術放在角色記錄裡（`已證實`）

```
法術記錄 = 角色記錄 + 0x200 + 16 × 參戰者[+0x26]
```

**角色記錄 `0x200` 起、每 16 byte 一筆、共十六筆就是法術**，版面與商品記錄相同
（RE-075）。`Member.PackCount` 數的正是這一份裡非空的筆數——指令列因此在「有法術」
時才放出施法那一格（`0x22A82`）。

程式只讀四處：

| 位移 | 內容 |
|---|---|
| +0x08…+0x0B | 四格護符，擋招要比 |
| +0x0C | 效果編號 |
| +0x0D | 持續回合的骰式 |
| +0x0E | 效果強度的骰式；bit 7 是「這一手要不要先選目標格」 |

## 2. 骰式（`已證實`）

```
v     = (碼 >> 1) & 0x3F
骰面  = [0x00D4 + (v & 7)]        ; 2 3 5 7 9 11 19 99
骰數  = v ÷ 8 + 1
```

**與武器傷害碼那一套（`DamageCode`）差一個位移**——武器是 `(碼 >> 2) & 7` 取骰面、
`碼 >> 5` 取骰數。兩邊各有各的反組譯出處，不要合併成一支。

擲的順序是**先持續、後強度**（`0x283B2` 與 `0x28420`），共用同一顆亂數，對調會讓
整串結果不同。

## 3. 有沒有東西可以施（`已證實`）

`+0x0E` 的 bit 7 沒設就看施法者面對的那一格（`sub_24BB6`），設了就看選好的目標格
（`sub_24C35`）。兩邊都沒人就印 **0x169**（`casts a spell, but nothing is there!`）。

## 4. 擋不擋得住（`已證實`）

目標倒下（`sub_22866`）就一定擋不住。否則拿法術的四格護符與目標那一格比——
**敵人看怪物記錄 `+0x1D`、隊員看角色記錄 `+0x28`**（`sub_22229` 決定看哪一份）：

```
高 nibble 要相同
那一格 ≥ 0x50 時，護符的低 nibble 還要 ≥ 目標的低 nibble
四格有一格中就穿得過去
```

一格都沒中就印 **0x16A**（`casts a spell, but it has no effect!`）。
過了就印 **0x16B**（`casts|S at|F.`），`|S` 是法術的名字。

## 5. 三種效果（`已證實`）

**效果 6：指定部位。**要選目標格的法術隨機挑一個部位（`rand(6) − 1`）；否則畫出
目標的人形，印 **0x184** ＋ **0x186**（`hurt`）或 **0x185**（`heal`）＋ **0x16C**
（部位清單），等一個 `1`…`6`。

施法者的 `+0x27` 非零是**負面**：`sub_277F4` 把強度打在那個部位上。零是**正面**：
那個部位補上強度，上限是它自己的上限；腿治好而且對象是隊員時再 `sub_21D94`。
這一條**不掛倒數**——它把 `+0x0D` 設回 0。

**效果 5**：`[0x322E + 2 × 參戰者]` 加減「強度 × 2」，減不到零以下。**那一格是疲勞
累計**——`sub_23683` 把它折算成 `50 × 疲勞 ÷ [0x1C50]`，攻擊值再乘它除以 200 扣掉；
每回合自然恢復一點，休息一回合恢復三成（RE-100）。

remake 這一版對效果 5 什麼都不做（但仍算打中）：那一條疲勞鏈還沒進戰鬥的規則層，
`Actor.Fatigue` 是另一格（`+0x2D`）。要做要連 `[0x1C50]` 的語意一起解。

**效果 1…4、7、8**：查 `[0x12A4 + 效果 − 1]` 得到參戰者記錄的欄位偏移再加減強度
（正面上限 0xFF、負面下限 0），並掛上倒數。表是 `08 09 0A 0C 2C 2C 2E 2F`：

| 效果 | 欄位 | remake |
|---:|---|---|
| 1 | +0x08 力量 | 有 |
| 2 | +0x09 快捷 | 有 |
| 3 | +0x0A 洞察 | 有 |
| 4 | +0x0C 智力 | 有 |
| 7 | +0x2E | **語意未解，不動**（RE-122：全檔只有 `sub_26CD5` 讀它，作用是把 `word_34A12` 減十倍）|
| 8 | +0x2F | **語意未解，不動**（同上，減的是 `word_32380`）|

效果 0 或大於 8 什麼都不做。

## 6. 倒數與失效（`已證實`）

效果 1…8 設目標的 `+0x0D = 1` 與 `+0x30 = 持續回合 + 1`。回合開始時
（`sub_1E3A8:0x20F01`）倒數，到 0 就**把屬性整批重算回原值**——原版重新呼叫
`sub_2198A`（隊員）或 `sub_2215A`（敵人）把角色／怪物記錄搬回參戰者記錄，
所以加成不必個別記帳。接著印 **0x173**（`'s spell wears off!`）。

remake 由 `BeginPlanning` 跑倒數、把過期的記進 `State.WoreOff`，呼叫端一位一句。

## 7. 最後那一句（`已證實`）

```
0x16D「The spell has a]」
0x16E + min(強度 ÷ 8, 3)     ; mildly／markedly／strongly／powerfully
' '                           ; 這個空白不在任何記錄裡，是程式印的
0x106 + 施法者[+0x27]         ; Positive／Negative
0x172「 effect.」
```

## 8. 不授權實作的範圍

- **選部位那一次互動**。原版對「不用選目標格」的法術會在執行段中間畫出目標的人形、
  等玩家按 `1`…`6`；remake 沒有那個機制，所以照原版另一條走隨機部位。
- **效果 5 的疲勞鏈**與**效果 7／8** 的欄位語意（第 5 節）。

已經做完的：法術從角色記錄抽出來一路接到 `battle.Member`，指令列在「有法術而且手上
空著」時放出那一格，規劃段走「Which Spell?」→「Select Affect」→ 選目標格三步，
執行段印施法與效果兩句。實跑收據 `docs/verification/battle-spell/`。

## 9. 實跑

`docs/verification/battle-spell/`：Warder 被伏擊，第一回合先丟掉手上的射擊武器
（**原版有武器就不放出施法那一格**，`0x22A82`），第二回合才施得了法。四張畫格涵蓋
兩張清單與執行段那兩句。

## 10. 還沒解的

參戰者記錄 `+0x2C`、法術護符那四格到底代表什麼屬性，以及 `word_34A12`／
`word_32380` 這兩個被效果 7／8 打的全域是什麼。

已經解掉的兩個（RE-121／RE-122）：

- **法術的母表**是建築 payload `0x100` 起那一塊，由 SCROLL 那一格賣（一筆 16 byte、
  固定八筆、價錢在 `+0x0F` × 10），買下抄進角色 `0x200`…`0x2FF` 十六格的空槽。
- **`[0x1C50]`（疲勞的分母）**由 `sub_21AC4` 填成
  `[參戰者 + 0x08] + ([參戰者 + 1] ? [本體 + 0x15] : [本體 + 0x20])`，
  也就是力量加本體記錄的某一格；那一格是什麼還沒解。
