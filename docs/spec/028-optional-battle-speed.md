## 不依賴版面決定的完成條件

1. 三項均可個別關閉，全關時保留已核准忠實路徑，不額外消耗遊戲亂數。
2. 改變呈現等待不得改變行動次序、法術倒數、疲勞、世界時間或傷勢等規則。
3. 重複命令必須重新檢查當下人物、裝備、彈藥、地形與目標合法性，
   不能重新送出舊按鍵串，亦不能保留失效的陣列索引。
4. 需要玩家回答的問題不得被自動代答：逃走、拾取、施法選部位、戰利品、
   存檔及退出均須有明確停止點。新一輪與消息確認的取捨見下節。
5. 設定須經正式操作可調、保存、重啟及再次生效；只提供命令列旗標不算
   玩家功能完成，只有保存鍵也不算功能完成。
6. 比較開關前後的規則結果及正常 GUI；涉及 RND 時，dosgolem 原版與重製版
   均固定測試 seed 並記設定點。原版對拍保持全關；加速開啟時屬重製版等價性驗證。

## 待共同決定的細節，不冒充已核准需求

- 重複上一指令是「預填後可修改並確認」，還是「一次套用且立即結束該人的規劃」；
  移動方向與射擊目標失效時的回退也要隨該決定明訂。
- 「未接敵」採可見敵人、距離／攻擊可達性，或本輪沒有敵對結果中的哪一種定義；
  因各定義會在不同時點停止，不能由 agent 隱性替玩家選擇。
- 動畫速度涵蓋哪些已有播放器；尚無 READY 的飛行動畫不因本規格自動取得實作授權。
  倍率與播放期間可否切換須以實際可丟棄原型確認。
- 玩家入口、快捷操作及滑鼠等價操作需在可見原型上確認，再定正式版面。
