沿[SPEC-039](../spec/039-hd-art-ui.md#其他操作頁的原生hd呈現)及已核准的手繪、1920×1200、字型與欄位位置。
目前涵蓋目錄、角色選項、名冊、港務官、建角、肖像／盾牌編輯器、保存問句，以及商店、訓練、馬廄、法術清單、任務清單與人物資料。

新增手繪空白書頁與三個服務頭像，原生字模、面板及編輯器工具列來自隔離呈現。

其他人物、坐騎、裝備、徽章及未重繪圖示仍有EGA素材，不列為完整HD。

`capture.py`沿固定seed1與既有服務輸入比較兩側狀態，並檢查實際抵達編輯器與保存問句。
15組固定輸入每側145狀態相同；[比較頁](hd-native-ui-20261014/review.html)提供38張繁中EGA／HD畫格，
來源與權利見[截圖清冊](hd-native-ui-20261014/manifest.json)。這是重製兩種呈現的比較，不是原版DOS對拍。

真實視窗由標題走至選單與編輯器，完成30個F10設定事件，五組狀態各保持。
四組固定畫面往返完整畫格零差；畫布模式保留閃爍游標，以狀態核對。
1920×1200及960×600、滑鼠選色與畫點、中文保存問句、答否不寫檔及Ctrl+Q退出0均通過。
自訂圖的放大區及預覽與EGA逐像素相同。
結果見[檢查收據](hd-native-ui-20261014/check.json)與[真實視窗收據](hd-native-ui-20261014/gui-check.json)。

GUI隔離副本只增加繪製完成通知，工具等通知再送鍵及擷取；正式程式不加此診斷旗標。
音訊使用ALSA虛擬輸出，本批只驗介面及輸入，沒有新增人耳或音訊完成聲明。
最初缺ALSA、過早抓到前一場景、選色測試前置條件及大寫X未觸發問句的輸出均保留，沒有放寬一色階或重擲亂數。

## 已定位的中文確認視窗問題

既有 `book.CJKConfirm` 的視窗為282,174,396,84，文字仍在264,124及296,148，落在視窗外。
隔離原型改為312,192及384,216，沿既有三倍座標及行距，文字落入視窗。
本修正已重驗刪除確認與保存問句的受控畫格；正式程式修正另依READY審查接入。

及[本機清冊](local/hd-native-ui-20261014/retention.json)索引，核對與解開沿[保存入口](retained-evidence.md)。
重生先由Git0943d9f8取出366份來源，再套用相應輪次的覆蓋檔及原建置參數。
一般十三組採`overrides-v5/`；刪除確認、保存問句及GUI採`overrides-v6/`。

第六輪新增的通用白底背景會改變服務面板邊框，正式接入已縮限至中文確認視窗，另行驗證。
