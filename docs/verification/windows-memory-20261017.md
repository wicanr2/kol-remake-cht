# Windows 按需讀取與雙版本交付

本輪修復使用者回報的 Windows 開場後及切換手繪畫面直接關閉問題。
使用者電腦為 16 GB 記憶體，並核准按需讀取、動態釋放與 Wine 驗證。
原來在切換時一次保留全部 HD 像素及 GPU 紋理，前版 Wine 驗證曾達約 14.3 GiB。
開場後的玩家閃退尚未取得同一失敗收據；不能將兩種現象都稱為已證實的同一原因。

本輪依 [SPEC-039 記憶體修復契約](../spec/039-hd-art-ui.md#windows-記憶體修復契約)實作。
正式素材位元組、規則、配樂與 v3 存檔保持。
完整組索引、來源及幾何先驗，圖片在使用時讀取、驗 SHA-256 及解碼。
原生紋理預算為 192 MiB，縮放快取為 96 MiB，當幀使用者保留。
離開裝備頁釋放合成快取，回到 EGA 時釋放 HD 圖片；再切回時依目前場景重載。
這兩個預算不包含畫布、Ebitengine 與顯示驅動的開銷。

Windows `v.1.0.4-20261017` 提供兩種完整版及對應無素材引擎包。
純 EGA 包移除 832 份 HD 圖像與配套檔案，保留四首配樂及 F9。
未安裝完整 HD 素材組時，F10 的 HD 選項停用；兩種包共用 v3 存檔位置。
完整版只留本機，Release 僅上傳引擎包與校驗碼，Linux、macOS 與影片保持前版。

機械結果以[本輪收據](windows-memory-20261017/receipt.json)為準。
逐檔來源、封包、場景比較、正常視窗輸入與工具版本由收據索引。
驗證包括 13 個受控場景的 EGA／HD 釋放後重載、跨平台畫面與中文，以及實際 ZIP 的
正常開場、書本、選單、組隊、配樂及 F10。原一色階標準保持。
Wine 不等於 Windows 真機；受控畫面不宣稱新增原版 parity 或自然全任務通關。

重現工具位於[本輪 recipe](windows-memory-20261017/recipe/)，封包工具為
[pack_windows_variants.py](../../tools/pack_windows_variants.py)。只在 Docker 執行，
沿既有鎖版 Go／Wine／音訊映像、UID/GID 1000、無網路及有界資源。
本機完整證據與原工作區對照見[保存清冊](windows-memory-20261017/retention.json)；
保存方法及舊版證據見[共同保存入口](retained-evidence.md)。


## 驗證結果

| 項目 | 結果 |
|---|---|
| Windows 四個實際 ZIP | 兩個完整版及兩個合法資料匯入後引擎包均正常退出，版號一致 |
| 正常操作 | 標題、書封、目錄、建角選單進入與取消、選隊長進旅店、F9 及 F10 通過；純 EGA 的 HD 選項停用 |
| 受控畫面 | Linux／Wine 各 13 個場景、52 張畫格；EGA 往返零差，HD 往返、跨平台及相對前版最多一色階 |
| 完整版／引擎包 | 各模式六張流程圖，合計24張；中文與完整模型相同，沿 EGA 零差、HD 一色階門檻 |
| 記憶體 | Wine 使用4 GiB容器上限，無OOM；程序RSS取樣最高約2.74 GB。容器峰值包含檔案快取，完整數值保留在收據 |
| 失敗恢復 | 只破壞解壓測試副本的書頁PNG；偵測雜湊錯誤後回到EGA，顯示完整中文、保持模型並正常退出 |
| 日誌與音訊 | 無診斷旗標的預設啟動會建立kol.log；實際Wine／Oto輸出非靜音、無裁切，退出末秒靜音 |
| Go檢查 | cmd、UI、分層及新增讀圖／快取回歸通過；其他核心套件與素材深驗分階段通過。首次素材600秒逾時保留，補驗796秒通過 |

交付來源為435份Go／module。受控畫面捕捉後只改了一句HD讀取失敗提示，將缺字的
「已返回」改成現有字集包含的「已回到」。[差異證明](windows-memory-20261017/post-scene-notice-fix.json)
以反向替換後的完整檔案SHA-256核對；此提示由最終Windows包的壞圖負例另驗。
素材檢查、各階段測試與已失敗候選分開保留，不宣稱所有測試來自同一次命令。

切換計時包含驗證腳本的按鍵等待。Wine首次從送鍵到繪圖收據約15.8至22.8秒，
再次約1.6至3.7秒；這不是Windows真機載入時間。首次HD仍需載入，沒有把容器測試
宣稱為真機驗收。此次抽樣針對記憶體與切換，既有全量HD素材及其他驗收保持。

封包為`dist-all/v.1.0.4-20261017/`下兩個完整版與兩個無素材引擎包。
完整版分別18,860,390及1,292,965,557位元組；公開引擎包分別8,628,426及8,672,021位元組。
完整SHA-256見[正式收據](windows-memory-20261017/receipt.json)。
