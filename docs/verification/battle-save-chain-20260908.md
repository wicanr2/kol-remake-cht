# 戰鬥結算至完整保存的整合驗證

日期：2026-09-08。V01 局部驗證，沒有新增原版一致性聲明。

`cmd/kol/battle_save_chain_test.go` 使用三個受控結算狀態：勝利、撤退與競技場勝利。
經正式 `battleStep`、`writeBattleParty`、`buildCompleteSave`、`save.Write`、
`save.Read`、`savedParty`，核對下列資料跨邊界保留：

- 傷勢、破損頭盔的空值、降低的軀幹耐久，以及未受損的其他配件。
- 普通勝利每人一次的金冠與冒險點數；撤退不發獎勵。
- 競技場只替參戰者升階一次、觀眾賭金正負結算一次、不發一般戰鬥獎勵。
- 隊伍順序對應非連續名冊槽位 `[7,2,15]`，發言者仍為第二人。
- 保存前後逐欄比較完整角色 DTO，包含空裝備與原始物品記錄。

最終測試以 remake seed=1 產生受控護甲破損前置狀態；此處驗證的是狀態轉接與
檔案往返，並未將生成結果當成原版骰式比較。護甲規則的既有 dosgolem 比較另見
SPEC-017；新的完整原版戰鬥仍需雙方固定 seed 與共同設定點。
本測試從結算狀態開始，不能替代正常 GUI 戰鬥、取得資格、下注輸入或住宿保存驗收。
