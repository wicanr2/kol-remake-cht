## 本輪修正

住宅告示依使用者核准 A，採「請勿／踐踏草坪」兩行。三個可見告示的指定裁切區與原型
逐像素零差；共改 1,986 像素，區外零差，英文模式零差。驗證使用明示的繪圖觀察輸入。
舊 3,080 鍵正常住宅旅程本輪未抵達 Shellernoon，不能拿它替代正常住宅可達證據。
[正式畫面](cjk-closeout-20261011/zh-residence.png)與[核准原型](cjk-closeout-20261011/approved-sign-A.png)已保存。
SPEC-016 的告示子契約保持 READY。

書本目錄原本把英文烘在 BOOKPICS[1]。中文模式改用既有空白右頁繪製七項中文，
選項編號、順序與原有操作不變。正常啟動 → 目錄 → 角色選項 → 返回，英中各五個狀態
完全一致；英文目錄與先前畫格零差，中文返回頁與初次目錄零差。最長譯名六字，
字寬上限 96 像素，小於安全寬 354；數字右緣 882 留在紙張內。目視確認無裁切或缺字。
兩個初版譯名與術語表不符，已改回「安裝新區域」「播放開場動畫」，重新核查通過。
[中文目錄](cjk-closeout-20261011/zh-contents.png)的靜態頁子切片驗收通過；翻書動畫另列。
