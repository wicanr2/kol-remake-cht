# 七城與世界連續手繪地圖

狀態：地圖背景與世界點位限定範圍 **CONFORMED**。沿使用者核准的手繪、1920×1200、原位置與F10；新素材縮小以降低容量。全量工作入口為[目前計畫](../../workplace/hd-full-20261016/plan.json)，其餘HD繼續。正式入口：[收據](hd-all-maps-runtime-20261017/receipt.json)、[來源與截圖清冊](hd-all-maps-runtime-20261017/manifest.json)、[六組比較](hd-all-maps-runtime-20261017/review.html)。

本批來源為TOWN3至TOWN7及世界TOWN0的六張64×64索引地圖與六張256×256圖集。240張不同畫稿及12個來源RGB完全相同的霍布城區塊形成252個位置綁定。第一、二城84張1254×1254原圖及綁定保持；八組共336區。原通行、門位、鏡頭、規則與v3保持。

新地圖交付768×768不透明PNG，原始生成圖另留本機。252區容量由932,763,127降為392,972,193 bytes，減少57.87%。清冊分別保存原始與縮圖的PNG／RGBA雜湊及尺寸，使用Pillow9.4.0 LANCZOS。遊戲仍以原96像素格及固定整數雙線性取樣呈現。

已完成504個正式受控鏡頭，每張新地圖84個鏡頭覆蓋4096格及42個區塊。3360個觀測漢字缺字0，中文與可序列化狀態保持、EGA往返零差、交付圖獨立合成最多一色階、視窗外零差。首輪世界點位沿舊EGA函式，手繪RGB未被反相；補驗改為同12×12矩形逐通道反相，座標、次格及閃爍保持。首輪收據排除該矩形，補驗另含完整點位，不覆寫歷史。

世界點位修正後另驗84個鏡頭，840個觀測漢字缺字0，含完整點位的獨立合成最多一色階，視窗外零差、EGA往返零差、HD往返零差。GPU負例另確認非EGA底色可見點位，以及不同typed世界格子在繪製前拒絕；舊原圖及來源指紋亦均保持。

城鎮與世界各在1920×1200鍵盤、960×600滑鼠完成切換，共24個設定事件，完整可序列化場景狀態保持，實際視窗HD往返最多一色階。這份GUI程式先於世界RGB點位修正，F10控制程式未改；修正後的84鏡頭另驗完整畫布往返。兩階段程式與雜湊分開保存，不混稱同一程式。GUI只更新既有畫面設定，凍結受控場景，沒有新增正常旅程聲明。

417份正式Go／module來源維持，新增252份PNG後共有730份HD資產。全套回歸通過，資產套件332.133秒、入口188.453秒；點位修正後UI48.187秒及sceneverify242.598秒通過。縮圖下限767、來源數量／指紋、缺區、透明、原子接入與世界typed來源負例均涵蓋。本批沒有新增存檔程式，既有v3測試由全套執行。

手繪細節與局部材質接縫不宣稱原版逐像素幾何一致。原型來源與整城診斷、完整畫格、生成原稿及各階段程式仍在全量工作區保存；完成全量工作後依[證據保存入口](retained-evidence.md)封存及清理。README及比較頁只展示768×480縮圖，清冊保留原960×600／1920×1200畫布的來源SHA-256，沒有把預覽尺寸當成遊戲畫布尺寸。

本批限Linux Docker受控場景，不新增原版oracle、正常全旅程、Windows／macOS真機或自然通關聲明。世界天候、城鎮頭盔、世界事件、戰場、傷勢與片頭仍依[SPEC-039](../spec/039-hd-art-ui.md)續作。現行Release及tag保持。
