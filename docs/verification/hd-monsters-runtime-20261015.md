# 怪物資訊框與遭遇群像HD正式驗收

32種怪物已接入開發版，範圍限資訊框與遭遇群像，為有限CONFORMED。沿既有手繪、1920×1200、原位置與遊戲內F10，原規則與kol-save-v3保持。

[八組同狀態比較](hd-monsters-runtime-20261015/review.html)、[正式收據](hd-monsters-runtime-20261015/receipt.json)及[素材清冊](../../assets/hd/first-slice/monsters/manifest.json)為入口。完整來源與提示在素材組的generation.json；完整畫格及歷史失敗由[保存入口](retained-evidence.md#怪物hd正式接入)保留。

| 項目 | 結果 |
|---|---|
| 正式來源 | 402份Go／module，276份HD資產，32張原始生成PNG |
| 實際遊戲呈現 | 32種資訊框及1／3／12隻群像，128場景512畫格 |
| 原生圖片與透明遮擋 | 獨立預乘alpha合成最多1／255，圖外0，錯圖號及反向順序反例拒絕 |
| EGA與中文 | RGBA零差，可序列化戰鬥狀態與文字紀錄一致，2237個實際字元缺字0 |
| 正常操作回歸 | 每側41狀態，中文、控制器及EGA保持 |
| 遊戲內F10 | 資訊框與12隻群像，兩種視窗、鍵盤及滑鼠，共24事件，戰鬥狀態保持 |
| 保存重載 | 正常住宿11狀態、重載5狀態，前版v3可讀且原檔不變 |

全套與sceneverify在401份來源通過。之後只抽出底層重畫函式並補失敗還原測試；402份來源的入口測試及完整GPU場景再驗通過。兩階段雜湊分開保存，資產與UI來源保持。

透明PNG完整保存，包括低alpha像素。第10、13張最大alpha254有效，舊檢查器的背景誤判已撤回。獨立CPU檢查依鎖版Go1.26.7及Ebitengine2.9.9的預乘契約；最初Pillow反預乘診斷保留，沒有放寬一色階。

正式擷取的前兩輪137退出保留為環境失敗。最後沿Ebitengine影像重用契約，改用單一正式模型、重用擷取畫布及2GiB Go記憶體預算，完整擷取正常退出；記憶體紀錄見memory-check.json。這些改動只在驗證工具，不改正式呈現或場景。

重生時先依保存入口還原本批workspace，沿原檔名執行build.sh、run-regression.sh及兩個檢查器。Docker image為kol-package:1.26.7-ebiten2.9.9-20261011-r1，專案唯讀掛/src、本批工作區可寫掛/out，使用UID／GID1000、network none及相稱的資源上限。完整原始樣本、v3與失敗只留本機。

這是受控重製畫面及最小正常回歸，沒有新增原版oracle、自然通關或跨平台真機聲明。戰場圖塊、傷勢、天候、地圖、片頭及其餘HD仍開放；現行v.1.0.2-20261013保持。
