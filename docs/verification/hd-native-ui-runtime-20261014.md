狀態：本批**有限CONFORMED**。沿[SPEC-039](../spec/039-hd-art-ui.md#其他操作頁的原生hd呈現)接入已展示的書頁、三個服務頭像、原生中文字、面板與編輯器。
基底0943d9f8；正式374份Go／module，全套internal／cmd與sceneverify測試通過。
[十五組正式比較](hd-native-ui-runtime-20261014/review.html)提供38張繁中畫格，來源、實際畫格及權利見[清冊](hd-native-ui-runtime-20261014/manifest.json)。
目前只驗Linux容器。法術編輯、完整物品頁、其他人物、坐騎、裝備與圖形仍需續作，全畫面HD目標保持開放；舊Release未重打包。

## 接入與修正

頁面素材採`kol-hd-pages/1`，四張圖、六個原版來源圖號／PNG及RGB指紋完整核對。
缺檔、損壞、尺寸、圖號、重複來源與不安全路徑拒絕整組載入。
HD呈現只在單次呼叫接管字模、共用圖像及面板；結束、錯誤與巢狀呼叫會還原，EGA及其他畫布保持。
未驗法術編輯、完整物品頁及長對話仍走原入口，不把回退算作HD完成。

既有CJKConfirm文字原在視窗外，正式移至312,192及384,216，實際中文與字模測量均落在框內。
原型第五輪保存一般十三組，第六輪保存兩個問句及GUI。第六輪通用白底修正曾改到商店邊框，
正式限定中文確認內框後，固定374份來源重建並通過全部對照；原失敗畫格保留。

重載腳本末尾ESC不受既有城鎮批次工具支援，保留失敗輸出後改為已執行成功的四步輸入。
沿同一容器、來源及命令續驗未完成流程；前面已通過的十五組、英文與既有HD畫格直接重核，沒有重跑遊戲抽樣。

實際視窗沿正式來源建隔離副本，只加入Draw完成通知，沒有修改呈現、輸入或狀態，也沒有把診斷旗標加入主程式。
GUI來源清冊另分格式化前與實際格式化後的main雜湊；舊標示保存，最終main由相同來源與gofmt重建後核對，未重跑遊戲。
音訊使用ALSA虛擬輸出，本批沒有新增聆聽聲明。
