# 受控場景與中文畫面驗收

本輪依使用者確認的 [SPEC-040](../spec/040-controlled-scene-acceptance.md)執行。
狀態：**指定場景通過**。固定種子 1、驗收專用建置、隊伍鎖血、命中後傷害 20 倍。
不要求重新走完歷史長任務；場景準備與原版對拍分開記錄。

固定書本、建角、七城建築與初次規劃沿用[前次收據](cjk-closeout-20261011.md)，
本輪補服務畫面與受控戰鬥至結局。完整雜湊與條件見[收據](controlled-scenes-20261011/receipt.json)，
保留畫格見[PNG清冊](controlled-scenes-20261011/manifest.json)。

| 範圍 | 結果 |
|---|---|
| 商店、訓練、馬廄、法術、接任務、任務清單 | 六組新建輸入抵達對應畫面；中文、主要圖像與操作列目視通過 |
| 書本至城鎮、資料頁、招募、城鎮往返 | 四條短路徑重播成功；與六種服務共168張新繁中畫格 |
| 受控戰鬥 | 單人、相鄰一隻同等級獨眼巨人；進場、規劃、執行、勝利、獎勵及戰利品已抵達 |
| 英中狀態 | 每側33個狀態，僅豁免兩個顯示文字清單；其餘差異0 |
| 鎖血與英文 | 隊員頭／胸維持16；英文33張圖與中文修正前相同；驗收未寫入存檔 |
| 結局 | 七段均有繁中畫格；真實譯文的畫布、圖框與文字互疊測試通過 |
| 翻譯與字模 | runtime檢查缺項0；6115字串缺字0 |

結局原本把16×18中文字模畫在320×200的定位上。修正為圖像與文字座標共同乘三。
第四及第六段的中文行數較少，另將回左欄的末段明確定位到圖下，避免覆蓋圖片。
只改中文呈現與兩筆譯文定位，不改結局觸發、段落順序或等待按鍵。

正式套件回歸、驗收模式戰鬥與適配器測試通過。`sceneverify`標籤以外的程式不含鎖血與倍率參數；
驗收模式要求腳本、trace與截圖，禁止保存，包括舊v1自動選擇的保存目的地。
工具為 [verify_controlled_scenes.py](../../tools/verify_controlled_scenes.py)，Docker內分
`prepare`、`captures`、`battle`、`guards`、`seal`五階段，工作樹掛在`/src`，本輪輸出掛在`/out`。
建置環境為 `kol-package:1.26.7-ebiten2.9.9-20261011-r1`。

本輪保留17張代表畫格。人物姓名、玩家輸入與精靈語法術名依現行契約保留。
結局完成後的空白終端畫格不列為通過場景。舊缺輸入、逾時及原版差異保存原等級，
不要求以長流程重跑；本收據不宣稱所有亂數分支、正常全旅程或原版整場一致。
既有v1封包不重包，新修正位於開發來源。
