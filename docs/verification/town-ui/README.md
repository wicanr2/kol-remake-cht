# 城鎮畫面的組成

更新日期：2026-09-01

書頁是一張烘好的素材，城鎮畫面不是——它是底圖之上疊了幾塊。要對拍就得先知道底圖是
哪一張、上面疊了什麼。`tools/decompose_town_frame.py` 用抽出的全螢幕素材逐張與畫面
相減取最小差異當底圖，再對差異像素做四鄰連通分群，最後檢查**分群之外的殘餘差異必須
為零**——不為零就代表底圖判斷是錯的。

## 半途之家旅店（`inn-decomposition.json`）

底圖是 320×200 的紅磚畫面。`BOOKPICS[3]` 與 `KOLMPICS[0]` 是**同一張圖**
（PNG SHA-256 `83e871eb…fe73` 相同），書本與城鎮各存一份；城鎮用的是 `KOLMPICS[0]`。
分群之外殘餘 0 像素。

| 區塊 | 矩形 | 內容 |
|---|---|---|
| 對話框 | (102,84) 199×72 | 店主台詞，黑底白字 |
| 店主肖像 | (8,64) 92×68 | `TWN7PICS[12]`（88×64）＋投影；外框是素材自帶的 |
| 標題框 | (102,58) 199×24 | 地點名與店主名兩行 |
| 隊員頭像 | (14,1) 47×52 | `CHARPICS[47]` 畫在 (16,2)，下方是名字前五個字元 |
| 圖示格 ×6 | (32+32i,170) 24×22 | 見下表 |
| 滑鼠游標 | (143,95) 17×7 | 原版自畫，remake 沒有這個元素 |

白框表示目前選定的圖示；其餘是藍框。`<`／`>` 移動白框（末格繞回第一格），
Return 執行。

## 文字版面

標題框與對話框的內文用 **8×8 大字型**（書頁內文用的是 8×6 小字型），字格從 x=104 起、
行距 8、每行 24 格。標題兩行置中，起始格 ＝ (24 − 字數) / 2 向下取整；台詞靠左。
隊員名牌用 8×6 小字型，只畫名字的前五個字元。

## 對拍結果

`../remake-parity/town-inn.json`：八對（六個圖示白框位置、單人隊伍、招募後的兩人隊伍）
全部通過，允許差異區之外零像素差；允許區只有原版滑鼠游標。

## 戶外地圖（`outdoor-decomposition.json`）

在旅店按 DOOR 會走到戶外地圖。底圖仍是同一張紅磚圖，上面疊五塊：

| 區塊 | 矩形 | 內容 |
|---|---|---|
| 地圖視窗 | (103,57) 194×98 ＋投影 | 白框 1 px，框內 192×96 從 (104,58) 起 |
| 城鎮徽章 | (24,85) 56×57 | `TWN7PICS[0]`（含共用 AND-mask），2,754 個不透明像素零差異 |
| 日期框 | (14,57) 67×15 ＋投影 | 白框黑底；小字型白字 `Apr 1`(24,59)、`AD  1100`(16,65) |
| 隊員頭像 | (14,1) 47×52 | 與旅店同一塊 |
| 圖示格 | (32,170) 24×22 | 只有一格，`KOLMPICS[5]`（DOOR），零差異 |

徽章的連通分群報成 56 高、殘餘 3 個像素，是因為最後一列只剩三個孤立的不透明點，
四鄰分群把它們切開了；逐像素比對確認整張 56×57 都對得上。

### 地圖視窗是捲動的磚塊圖，不是一張固定圖

- **視窗內容不是任何一張抽出的素材**：從地圖上取八段 24 像素的指紋，去 752 張 PNG 的
  像素緩衝區搜尋，**全部零命中**；把同尺寸的 192×96 素材逐張對位比較，最好的一張
  （`TWN7PICS[11]`）也差 12,535／18,432 個像素。
- **移動時視窗以 16 px 為單位捲動**（`town-outdoor-move-run1`）：往右一步視窗不動
  （只有隊伍圖示動，98.7% 相同），往右兩步整個視窗水平位移 16 px 後 97.9% 相同；
  往下兩步垂直位移 16 px 後 97.7% 相同。
- **磚格對齊視窗原點**：以 16×16 切格時，位移 (0,0) 的 72 格只有 47 種不同內容
  （65%），其餘 255 種對齊都在 87% 以上。

因此戶外地圖是 12×6 格、每格 16×16 的捲動磚塊圖，磚圖來源不在目前的抽取集合裡。
`KOLPICS` 的 0／8／12 是 `sub_19B29` 轉換的 raw-planar 資料、已知**不是** display
rectangle（RE-030），是磚圖來源的第一候選——但這still是假說，要讀 KOLTOWN 的地圖繪製
路徑才能確定。
