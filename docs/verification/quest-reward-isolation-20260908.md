# 任務回報獎勵的角色隔離修正

日期：2026-09-08。

`Member.TurnInQuest` 原先把建築 `GivesItem` 直接指定到手持與穿戴欄，
使兩名領獎角色與建築母表共用可變物品。背包是值複製，原先沒有同樣問題。
現改成每次成功交付建立獨立 `Good`，再寫入對應欄位。
`Good` 由純量、字串與值型別 `Dice` 組成，沒有需另複製的切片或指標。
