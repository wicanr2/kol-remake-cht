# 第二城連續手繪地圖驗收

第二城TOWN2畫稿與既有載入契約限定範圍CONFORMED。沿[SPEC-039](../spec/039-hd-art-ui.md#第二城位置地圖接入審查)及使用者已選A，保持1920×1200、原地圖位置與遊戲內F10。

正式[比較頁](hd-town2-maps-runtime-20261016/review.html)與[收據](hd-town2-maps-runtime-20261016/receipt.json)保存417份Go／module、478份HD資產。42張1254×1254原生不透明畫稿互斥涵蓋4096格；來源206個使用圖塊、實際14個門位。末項索引13與門數分開記錄。

| 核對範圍 | 結果 |
|---|---|
| 全套Go與sceneverify | 通過，含雙城來源、第二城缺區／缺PNG及整組原子交換負例 |
| 正式99場景396畫格 | 84鏡頭覆蓋4096格，另含14門位與城門林地 |

| 畫格 | EGA RGBA零差，獨立原生合成最多一色階，視窗外零差；相對隔離候選整張RGBA零差 |
| 正式F10 | 1920×1200鍵盤與960×600滑鼠共12事件，完整Outdoor保持，HD往返最多一色階 |
| 第一城 | 42張原圖、來源與位置綁定逐檔保持 |

畫稿以固定原始ZIP來源的TOWN2兩張PNG綁定。64×64八位灰階地圖是索引資料，256×256圖集是繪圖來源。原始ZIP SHA-256為`2b455e3c13ec7ecb727c918eefbe261fe741a460285bdd0e638a6aeb6ec49f46`，本輪重算相符。兩張純水區誤加城牆及一張黑影誤加水道的原稿保留；修正版、五段整城、14個門位及正式湖岸／木橋／城堡均已目視核對。手繪細節不宣稱原版像素幾何一致。

正式程式SHA-256為`3771796a1ffbecaaed6d6d960ae6afb57791bbc5cfd5e980affe703b2128ecba`。完整生成圖片、提示、修正前後、受控模型、GUI狀態與腳本沿[本機證據入口](retained-evidence.md#第二城連續手繪地圖hd正式接入)保存。原生PNG不修改；來源綁定圖片僅適用目前private儲存庫，不主張公開散布權。

重生使用`kol-package:1.26.7-ebiten2.9.9-20261011-r1`，Go1.26.7／Ebitengine2.9.9，UID/GID1000:1000、無網路、8GiB、3CPU、256程序及1500秒外層逾時。依[保存入口](retained-evidence.md)取出本批證據，在新的輸出目錄放入`formal-source-inputs.json`、`formal-city-cameras.json`及`build-formal.sh`；固定來源專案唯讀掛`/src`、輸出掛`/out`，以`sh /out/build-formal.sh`建置、測試與擷取。完整獨立比較另需封存的候選原圖、候選畫格及其清冊，沿`check-formal.py`執行；實際鍵鼠沿`formal-gui.py`執行。執行檔可重建，不以檔案存在代替通過。

原地圖、規則與v3程式未改。既有存檔回歸由正式全套執行，本批沒有新增正常第二城住宿旅程。原走路標記仍EGA；其他城鎮、世界地圖與全畫面HD仍待完成。本批採受控場景，不宣稱原版parity、正常全程通關或平台真機驗收。現行發行包與tag保持。
