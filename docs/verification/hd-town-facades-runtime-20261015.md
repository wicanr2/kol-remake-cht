F10使用真實遊戲更新、視窗與鍵鼠事件。GUI採準備門位及固定走路標記相位，只驗可序列化Outdoor，不代替正常全流程。正常操作及存讀檔另外執行，工具來源由[索引](hd-town-facades-runtime-20261015/regression-tools.json)保存。

此批只驗Linux Docker。六城其餘徽章、城鎮／世界地圖、戰場、傷勢、天候、片頭與其他事件仍開放；全畫面HD尚未完成。現行發行仍為v.1.0.2-20261013，本批未納入該封包或推廣片。
