## 正式接線

- `battle.BodyPanel` 從被檢視角色取得傷肢、上限、體力與疲勞；性別取正式隊員資料，
  敵人使用第三種人形。計算只讀戰鬥狀態，不改行動者、亂數或存檔格式。
- 規劃開始顯示本人，選目標時顯示可見人物；空格清空。招式與防禦子選單保留檢視者，
  取消回主指令列恢復本人；輪末及執行段不顯示舊資訊。
- `ui.BattleBody` 使用既有 MISCPICS 3..5 PNG，檢查 56×70，快取三張底圖與一張
  可變輸出。只改指定色號的遮罩像素，不修改共用素材或讓快取隨傷勢無限成長。
- 主戰場、法術／正負效果清單與戰利品畫面經同一呈現入口；人形依場景閘門顯示。
  體力及部位上限為零會回報資料錯誤，不把非法狀態畫成貌似正常的生命條。
