因此目前**不能聲稱所有遊戲文字都已翻譯**。上述靜態覆蓋由
[`tools/verify_runtime_translation.py`](../../tools/verify_runtime_translation.py)

玩家輸入的人名與必須輸入的原作關鍵字要保留規則用原文；譯文只能作顯示，
不能回寫原始資料的識別欄位或改變關鍵字比對。
