# 任務入口亂數接續正式驗收

日期：2026-10-07。狀態：SPEC-008 本切片有限 CONFORMED，父規格 READY 保持。

使用者閱讀[比較頁](local/quest-entry-rng-prototype-20261006/review.html)後說「那就繼續囉」，
本輪採已展示的原版亂數接續分支。契約見[SPEC-008](../spec/008-combat-field.md)。
只接任務入口的地形灑點與戰鬥來源，人物保存仍為v3。

原版證據沿[RE-287](../re/20261006-monster-pickup-normal.md)封存的正常任務5，
seed1在原版及remake啟動前固定一次。沒有新原版執行，不注入座標、物品或勝利。
正式來源342份輸入、340份Go，只改既有任務入口；十九套件通過。

同seed及按鍵重跑通過；失敗輸出另存，不當作正式產品缺陷。

建置、測試及畫格使用既有 `eob-remake-go:1.26.7-ebiten2.9.9-audio`，UID/GID1000:1000、
無網路、有界CPU／RAM／PIDs及外層逾時；Xvfb由trap回收。重建沿保存的 `build.sh`，
正式正常回放沿 `run-prefix.py`及`run-save.py`。原掛載為專案`/src:ro`、獨立輸出`/out`；
歷史觀察overlay需依[保存方法](retained-evidence.md)掛回當時路徑。
證據壓縮後核對雜湊與引用，再刪除這次工作目錄；執行檔可重建，只保留雜湊。

核對時將專案唯讀掛`/src`、本機證據父目錄唯讀掛`/out`，在同映像執行：

```sh
python3 -B /out/quest-rng-formal-20261007/verify.py
```
