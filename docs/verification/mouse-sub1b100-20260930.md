# 滑鼠：點肖像換發言者與選目標格的圖示列（#105、#94，2026-09-30）

## 結果

讀完 `sub_1B100` 的滑鼠分支（[RE-167](../re/RESEARCH-LOG.md)），兩個問題都有答案：

- 點隊伍肖像：原版把它轉成鍵盤 1…6，只在戶外走路、問誰開口、建築內一般圖示列與野外走路的輸入迴圈生效。
  remake 新增可點區域，點下去送同一個數字 token，走 SPEC-037 的換發言者流程。
- 選目標格那一層的圖示列：原版收滑鼠。remake 把 YES、U-TURN 兩格加進可點區域，排在戰場格前面。

## 不宣稱

- 沒有在真實視窗用滑鼠點過；驗的是可點區域與 token（`input.Hit`），滑鼠裝置到座標的換算沿用既有的圖示列。
- 原版沒有動態接手，全部是靜態證據。
- 圖示列的點擊語意（原版兩次點擊、remake 一次點擊）、右鍵（原版空白鍵、remake ESC）與地圖點擊走路，
  remake 與原版不同，已列成 `mouse-original-semantics`，等使用者決定。
