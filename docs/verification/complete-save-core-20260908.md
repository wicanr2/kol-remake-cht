# 完整角色保存核心驗證

日期：2026-09-08。範圍：SPEC-023 已審查的角色保存核心。

本頁保留接線前的驗證狀態；後續正式接線與 GUI 驗證已完成，見
[完整保存接線驗證](complete-save-integration-20260908.md)。

## 結果

`internal/save/characters.go` 新增獨立保存型別，完整保存角色能力、熟練度、
裝備、物品原始記錄、法術、教派、任務與進度。16 個固定槽位承載角色，
隊伍以槽位索引引用，發言者另以隊伍索引保存。

解碼前逐層檢查必要欄位與定長陣列，避免 Go JSON 解碼將短陣列補零、
忽略長陣列尾端或將數值 `null` 當成零值。解碼後拒絕空槽參照、重複隊員、
無效發言者、欄位數量超界及非 16-byte 的身上物品記錄。

新增測試確認已改變的能力／耐久、零金冠、零熟練度與空裝備往返保留，
重載副本不共用來源記憶體，離隊不刪角色，刪除不壓縮其他槽位；另有
14 組缺欄、陣列形狀與參照損壞案例，全部拒絕。

- Go 1.26.7；`GOWORK=off`、`GOPROXY=off`、`GOSUMDB=off`。
