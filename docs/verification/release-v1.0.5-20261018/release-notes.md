三平台均提供純 EGA、EGA＋HD 兩種引擎包，沿用同版已驗完整版的相同執行檔。

- HD 圖片使用時才解碼及載入，快取有容量上限，久未使用者釋放。
- 切回 EGA 時釋放 HD 快取，再切回時重新載入目前場景。
- 缺少完整 HD 素材時停用 HD 選項；可用 F10 在遊戲中切換。
- 四首配樂以 F9 獨立開關，切換畫面模式時持續播放。
- 遊戲規則、圖稿、配樂與 kol-save-v3 存檔格式保持。

這七個附件是六個引擎包及 SHA256SUMS.txt，**不含遊戲素材**。
匯入工具需要 Python 3.11 以上，請依包內 README.txt 匯入合法持有、已抽取且符合雜湊的資料。
純 EGA 匯入912份資料，EGA＋HD匯入1744份資料。

Linux／Wine四個實際引擎包已驗證匯入、開場、建角選單、組隊、旅店、F9、F10及缺HD停用；
測試使用4 GiB記憶體上限。固定seed1短流程24張畫格與同版完整版逐一比較。
macOS完成雙架構、bundle結構及兩種資料匯入驗證，仍無真機執行；Windows真機及Linux主機FUSE亦未驗。
