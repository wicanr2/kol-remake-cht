| 建角回填 | 接受肖像才提交新角色、持久 ID 與槽位；使用離線產生的職業／出生地資料；失敗可重試 | 正常 GUI 建立 NOVA、LUNA，重啟後選 NOVA 並招募 LUNA；建角寫入失敗與重試回歸通過 |

| 世界時間 | 保存剩餘時刻、時段、日、月、年與天候；讀檔同步日期、天候及世界操作列 | 檔案往返及非法日期／時段拒絕測試；受控 v2 重載後，以正常走路與露營將 1102 年 2 月 28 日推至 3 月 1 日 |
