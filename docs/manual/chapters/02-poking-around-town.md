# 在城鎮裡四處看看

<!-- handbook/page/006｜印刷頁 6–7 -->

現在你已建立一名角色——或者更好，一整隊冒險者——可以開始遊玩《武士傳說》了。所有
新角色都從布雷特爾鎮的巨魔剋星旅店出發，因此我們也從那裡開始。在目錄頁選擇
Play the Game（開始遊戲）。

## 巨魔剋星旅店

書本會翻到角色清單。如前所述，現在應選擇一名角色「帶領」隊伍。選定後，書頁會顯示
作者的最後一段訊息，接著由遊戲畫面取代。

隊伍成員沿遊戲畫面頂端排列。目前只能看到隊長，也就是選擇「開始遊戲」後挑出的角色；
當他邀請其他角色加入隊伍後，那些角色也會出現在旁邊。

畫面中央有三個視窗。右上方的小視窗寫著 `Trollsbane Inn, Elmu Trollhewer`，告訴你
目前身處哪間店家，以及店主是誰。Elmu 的肖像顯示在畫面左側，大型文字視窗則介紹旅店。

畫面底端的木製背景上釘著圖示板（Icon Plaque）。《武士傳說》以顯示在圖示板上的小型
方形圖片——稱為圖示（icon）——代替文字指令。遊戲中的大多數行動，都從圖示板選擇。

目前顯示的是 SPACEBAR（空白鍵）圖示。讀完大型視窗的文字後，按空白鍵顯示下一段文字。

> **SPACEBAR（空白鍵）**：電腦已顯示文字，正在等待你閱讀時便會出現。讀完畫面文字後，
> 按空白鍵告訴電腦你已準備繼續。

下一段訊息中，Elmu 向你問候，並詢問能為你做些什麼。請從圖示板新出現的圖示中選擇
回答。

> **DOOR（門）**：用來進出各種地點。在商店裡出現 DOOR 時，選擇它會離開商店、回到
> 城鎮；接近城鎮或村莊時選擇它，則會進入該地。離開城鎮時，DOOR 會帶你進入荒野。

選擇 DOOR 離開巨魔剋星旅店。Elmu 與文字視窗會消失，改為城鎮地圖與紋章。現在再選
DOOR 回到旅店；SPACEBAR 圖示出現時按空白鍵。

## 角色資料

<!-- handbook/page/007｜印刷頁 8–9 -->

下一個是 MIRROR（鏡子）圖示。選擇它查看英雄目前的狀態。

> **MIRROR（鏡子）**：顯示英雄的角色資料（Character Profile），列出所有相關資訊，
> 也能查看與整理角色裝備。

角色資料可快速查看屬性值、身高與體重、武器技能、金冠、冒險點數、移動率、魔法教團與
目前階級。金冠是王國通行的貨幣，可購買武器和其他裝備，也能支付魔法及武藝訓練費用。
屬性、技能、冒險點數、移動與階級會在本書後文詳細說明。

畫面底部的長條圖表示角色目前健康狀況。`DAMAGE`（傷害）代表戰鬥或環境造成的傷勢；
`NUTRITION`（營養）顯示近期飲食狀況。此刻長條呈藍色；若冒險者受傷或沒有好好進食，
長條會逐漸轉紅，表示累積的傷勢與營養不足。這些狀況如何影響角色能力，請見印刷頁 25。

角色資料畫面會出現三個新圖示：U-TURN（返回／取消）、ARMOR UP（穿戴裝備）與
VIEW PARTY（查看隊伍）。先選 VIEW PARTY；它會顯示整支隊伍的外觀。剛開始遊戲時，
畫面上可能只有一名沒有盔甲、也沒有攜帶武器的角色。隨著角色取得物品、隊伍加入更多
成員，這個畫面也會越來越有氣勢。

> **VIEW PARTY（查看隊伍）**：一眼查看整支隊伍。

接著選擇 ARMOR UP。

> **ARMOR UP（穿戴裝備）**：具有兩種功能。在角色資料畫面中，可檢查並觀看冒險者的
> 盔甲、武器與其他裝備；查看頭盔、項鍊等特定物品時，則可把該物品穿戴起來。

角色資料會改成裝備畫面，角色只穿著內衣站在其中。多數角色還會拿著一件武器，那是他們
起始時唯一擁有的裝備；若要盔甲和其他武器，就必須到城鎮裡不同商店交易。

裝備畫面右側列出角色可穿戴或攜帶物品的位置。選擇一個位置，就會在圖像上顯示小視窗，
簡要說明該物品。現在只有一件武器，因此選擇 `Weapon`（武器）。視窗中會顯示三類資訊：
中間一行是名稱；左下角是傷害；右下角有兩個數字，第一個是角色使用該武器的技能，第二個
是武器的負重值，也就是帶著它行動有多累贅。

U-TURN 旁會出現新的 EXAMINE（檢視）圖示；現在選擇 EXAMINE。

<!-- handbook/page/008｜印刷頁 10–11 -->

> **EXAMINE（檢視）**：進一步查看目前相關的事物。在裝備畫面中，它會顯示目前所選
> 物品的詳細資料；與商人或工匠交談時，則用來查看對方販售的商品。

裝備畫面會由物品畫面取代，詳細說明所選物品。武器的物品畫面會列出種類
（`TYP`），可能是單手、雙手，或兩者皆可；也會顯示攜帶位置（`POS`）、傷害（`DMG`）、
負重值（`ENC`）、金冠價值（`GC`）與狀況（`CND`）。盔甲還可能有合身費用（`FC`）及
防護值（`PRT`）：前者是角色為盔甲量身調整所需支付的金冠數，後者是盔甲提供的防護量。

新出現的圖示是 SHEATH（入鞘）、DROP（丟棄）與 PACK（收入背包）。先選 SHEATH。

> **SHEATH（入鞘）**：把手持或背包中的武器收進腰帶上的鞘。有些武器（例如弓）太大，
> 無法掛在腰帶上，使用這類武器時不會提供 SHEATH，只能拿在手上或放入背包。

裝備畫面重新出現時，武器欄會變空，剛才入鞘的武器則顯示在角色腳邊；那個位置表示武器
掛在腰帶上。若要把它拿回武器手，選擇 `Belt`（腰帶）位置，再按 EXAMINE。

物品畫面與先前大致相同，但武器位置會列為 `Belt`，並出現新的 READY（備戰）圖示，
位置就是剛才 SHEATH 所在之處。

> **READY（備戰）**：把所選武器拿在手中，準備投入戰鬥。戰鬥途中無法從背包翻找武器，
> 因此隨時至少要有一件武器處於 READY 或 SHEATH 狀態。若打算在戰鬥中切換武器——例如
> 同時攜帶劍與弓通常是好主意——就必須先在裝備畫面將一件入鞘、另一件設為備戰。

選 READY 前，先看看 DROP 與 PACK。在此選 DROP，冒險者會永久丟掉武器；選 PACK，
武器則會收進背包的六個口袋之一。選擇裝備畫面列出的各個口袋即可查看背包內容，背包內
物品也能像手上或腰帶上的物品一樣使用 EXAMINE。

> **PACK（收入背包）**：把目前手中的物品收進角色背包。
>
> **DROP（丟棄）**：永久丟掉物品；戰鬥中另有不同處理，詳見後文。

<!-- handbook/page/009｜印刷頁 12–13 -->

現在選擇 READY，讓角色在戰鬥發生時手上已有武器。畫面也會回到裝備畫面；接著選擇
U-TURN。

> **U-TURN（返回／取消）**：依所在畫面有兩種功能。多數情況下，它會回到目前畫面的
> 「上一層」；例如在物品畫面按 U-TURN 會返回裝備畫面。在城鎮或商店外按 U-TURN，
> 表示決定不進入，改回荒野或城鎮地圖。戰鬥中則會撤銷最近一次決定；例如選過
> WEAPON ATTACK（武器攻擊）後，可按 U-TURN 收回決定，再從現有圖示選擇其他戰鬥行動。

回到角色資料後，再按一次 U-TURN 返回一般遊戲畫面。此時 U-TURN 已被選取，只要按
RETURN 鍵即可。

## 與城鎮居民交談

畫面上的下一個圖示是 LISTEN（聆聽）。選擇它，聽聽 Elmu 是否知道有趣傳聞；必須按
SPACEBAR 才會看到他的回答。

> **LISTEN（聆聽）**：詢問城鎮居民最近是否聽到重要消息、流言或有趣故事。仔細留意
> 回答；對方特別強調的字詞，可能是他想進一步談論的主題——當然，他會等你主動提起。

Elmu 回答：「所有精靈都住在 Lintle 平原。我年輕時曾在那裡獵捕野生 Bronk。」

人們告訴你的話未必正確、重要，甚至未必是真的。儘管如此，仍應盡量記住居民的說法，
因為不起眼的事實或傳聞，往後可能派上用場。

讀完回答後，可再次按 LISTEN 繼續詢問。通常最好問到對方無話可說；他會明白告訴你，
已經把聽到的一切都說完了。

圖示板上的下一個圖示是 MOUTH（交談／進食），現在可以選擇它。

> **MOUTH（交談／進食）**：與城鎮居民互動時，可詢問任何主題。選 MOUTH，用鍵盤在
> 大型視窗輸入問題，完成後按 RETURN 鍵。在裝備畫面檢視裝有食物的口袋時也會出現
> MOUTH；此時選擇它會吃下食物。

Elmu 說話時特別強調 `Bronk`——你能看出來，是因為這個字以大寫開頭。居民把某個字
大寫時，可能表示他還能提供更多相關資訊。若要追問，用鍵盤輸入 `What are Bronk?`
（Bronk 是什麼？），再按 RETURN 鍵。

Elmu 的回答會出現在大型視窗。他可能會說：「沒……

……聽過 Bronk？那是種有六條腿、還長著一對相當醜陋腦袋的小野獸！」以後看到 Bronk，

## 招募同伴

下一個是 REST（休息）圖示。在旅店裡，REST 會讓冒險者投宿一晚並保存遊戲；在修道院，
REST 則表示請修士讓你躺下接受治療。現在先跳過，選圖示板最後一個 COMPANION（同伴）
圖示。

> **COMPANION（同伴）**：造訪旅店時顯示目前住在該旅店的所有冒險者。若要將其中一人
> 加入隊伍，從清單選擇姓名，再按 RETURN 鍵或選 YES（是）圖示（見印刷頁 17）。

大型視窗會列出目前旅店的所有角色。因為遊戲才剛開始，除了先前選定的隊長之外，你建立的
其他角色都會出現在這裡。選一名角色，按 RETURN 鍵或選 YES；該角色圖像會出現在畫面
頂端、隊長旁邊，接著返回巨魔剋星旅店的一般圖示列。

重複「選 COMPANION、從清單選角色、按 RETURN」的步驟，直到組成冒險隊伍。一次最多
可帶六名冒險者出發。

隊伍有多名冒險者後，可以看到其中一人的圖像外框是白色，其餘則是藍色。進入商店與店主
交談時，白框角色就是發言者。通常最好由魅力最高的英雄代表隊伍說話；選擇另一名角色的
圖像即可更換發言者。

## 行走於布雷特爾

除了在旅店選 REST 保存之外——遊玩一段時間後才需要——巨魔剋星旅店目前能做的事都已
完成，現在可以探索布雷特爾。選 DOOR 離開旅店。

畫面中央會換成一組新視窗。左側小視窗顯示目前日期與布雷特爾鎮徽，大型視窗則顯示
布雷特爾的戶外地圖。地圖中央建築就是隊伍剛離開的巨魔剋星旅店；隊伍在城鎮地圖上以
不斷左右掃視的騎士頭盔表示。

可用方向鍵在布雷特爾移動；若具備相應硬體，也能使用滑鼠。詳細移動操作請參閱
《武士傳說》參考卡。

先沿巨魔剋星旅店前方的主要街道向南走。道路在交叉口終止時轉向西方；往西走幾步，會
看見一棟小屋。通往小屋的路徑表示它可以進入；走到正門前仔細查看建築。

抵達門口時，城鎮地圖會改成面前建築的圖像，並出現兩個熟悉的圖示：DOOR 與 U-TURN。
從圖像可看出這是馬廄。你尚未準備進行荒野長途旅行，不需要坐騎；選 U-TURN 離開馬廄，
回到城鎮地圖。
