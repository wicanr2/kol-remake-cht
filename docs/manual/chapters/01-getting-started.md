# 開始遊戲

<!-- handbook/page/003｜印刷頁 1 -->

啟動《武士傳說》時，畫面上的書本就是通往阿什塔拉瑞亞的門戶。那是一個充滿榮耀與
危險的中世紀王國，也是一片奇幻土地；終有一日，你會在歌謠與故事傳頌的英雄中占有一席
之地。按下任意鍵翻開書本，你的冒險就此開始……

目錄頁上列有多個選項。選擇一項，書頁便會翻到對應內容。

Credits（製作名單）、Forward〔原文如此，疑為 Foreword，前言〕及 Dedication（獻詞）
是作者留下的訊息。讀完後按空白鍵，即可翻回目錄頁。

Install New Region（安裝新區域）可把冒險擴展到阿什塔拉瑞亞以外。探索完阿什塔拉瑞亞
後，獨立的《武士傳說》模組將帶你前往鄰近的 Salynn、Bamidor、Tsadith 與 Astrikan。
Character Options（角色選項）可查看冒險者名單及其目前所在位置，也能建立新角色或
刪除舊角色。角色選項頁內還有數個編輯功能，可修改角色圖像與盾牌，讓每名角色各具特色。
稍後還會回到這個選項，因為開始《武士傳說》前，必須先建立角色。

<!-- handbook/page/004｜印刷頁 2 -->

Play the Game（開始遊戲）會正式展開冒險。選擇這一頁後，系統會要求你從角色清單中
選出一名英雄。這名冒險者將成為隊伍中非正式的領隊；開始遊戲後，他可以招募其他由你
建立的角色加入遠征隊伍。

第一次遊玩《武士傳說》時，你會看見一名勇猛戰士在漆黑的暴風雨夜裡走近。Run the
Intro（播放開場動畫）可再次觀看這段內容。開場動畫播放期間隨時按下空白鍵，都會回到
主選單書本。

## 建立角色

在目錄頁選擇 Character Options（角色選項）。翻頁後會出現另一份選單；選擇
Create Character（建立角色），書頁會再次翻到題為 New Character（新角色）的頁面。

### 名字

建立角色的第一步是取名。用鍵盤輸入最多 16 個字母與空格。遊戲畫面在角色圖像旁只會
顯示名字的前四個字母。

按 RETURN 鍵確認名字。若要取消已輸入的名字並返回角色選項，按 ESCAPE 鍵。

### 種族

接著選擇角色種族：人類、精靈、矮人或凱爾登。人類就是一般人；精靈皮膚白皙、親近
自然，並以弓術聞名；矮人身材矮小而結實，熱中於劈砍巨魔與囤積黃金。凱爾登則是
阿什塔拉瑞亞的新來者，神祕而少為其他族群所知。多數凱爾登身高超過七英尺，憑藉巨大、
如皮革般的雙翼飛越王國。關於凱爾登與阿什塔拉瑞亞其他種族的詳細資料，請參閱本書
「阿什塔拉瑞亞的種族」一節。

選定種族後，按 RETURN 鍵或滑鼠按鈕確認。若要取消並改選其他種族，按 ESCAPE 鍵。

### 性別

選定種族後，必須選擇性別。選擇男性或女性，再按 RETURN 鍵或滑鼠按鈕。若改變心意，
按 ESCAPE 鍵即可取消。請注意，矮人與凱爾登只能選男性；基於阿什塔拉瑞亞人也不知道的
原因，這兩族的女性不從事冒險。

### 職業

選定種族與性別後，接著選擇職業。這可能是最重要、對新玩家而言也最困難的決定，因為
職業會決定角色的屬性值、基礎技能等級與初始裝備。現在只要挑選一個聽來有趣的職業，
再按 RETURN 鍵或滑鼠按鈕即可；稍後可在「進階玩家」一節閱讀所有角色職業的資料。

按 RETURN 鍵或滑鼠按鈕確認職業時，遊戲會依所選職業隨機產生角色屬性值。選擇
Reroll Stats（重新擲骰）可再次產生屬性，次數不限；對屬性值滿意後，選擇
Accept Stats（接受屬性）。

### 角色圖像

最後選擇遊戲中代表角色的圖像。按 RIGHT ARROW（右方向鍵）與 LEFT ARROW（左方向鍵）
瀏覽可用圖像，找到最符合角色的圖像後，按 RETURN 鍵確認。完成後角色會存入磁碟，
書頁也會自動翻回角色選項。

### 建立其他角色

《武士傳說》允許最多六名角色同時冒險，但隊伍中的每一名角色都必須由你建立。只需為
每名冒險者重複上述建立流程；完成一名角色後，他就會存入磁碟並登錄在角色清單中。

## 其他角色選項

<!-- handbook/page/005｜印刷頁 4–5 -->

建立角色並回到目錄後，再選 Character Options（角色選項），看看這份選單的其他功能。

### 角色清單

選擇 List Characters（角色清單）。翻頁後會顯示角色磁碟中所有角色的完整名冊；左頁
依建立順序列出角色姓名，右頁則列出每名角色目前所在位置。

位置文字的前十個字母是旅店名稱的縮寫，後面接著旅店所在城鎮的三字母縮寫。例如，所有
新角色都出現在布雷特爾的巨魔剋星旅店，因此位置會顯示為 `Trollsbane, BRT`。

一張角色磁碟最多可保存 16 名角色，但可建立的角色磁碟數量不限。角色也能在磁碟間轉移：
啟動遊戲，從第一張角色磁碟的清單組成冒險隊伍；取出該磁碟並插入第二張角色磁碟，再把
隊伍存回旅店（見印刷頁 21），即可將他們轉移到新磁碟。

查看完角色清單後，按任意鍵回到角色選項。

### 刪除角色

若要從角色磁碟抹除一名角色，選擇 Delete Character（刪除角色）。書頁會翻到角色清單；
選擇要從名冊移除的角色，再按 RETURN 鍵或滑鼠按鈕。

畫面會出現視窗，詢問是否確定刪除。刪除的角色無法復原，因此務必再次確認選對了角色。
若選錯角色或決定不刪除，選擇 No（否），便會返回角色選項且不刪除任何角色；選擇
Yes（是）則會刪除所選角色，再返回角色選項頁。

### 編輯圖像或盾牌

每名角色用於戰鬥、主要遊戲畫面與裝備畫面的獨特圖像，已賦予他一定程度的個性；你仍可
進一步修改戰鬥圖像，或修改角色的巨盾（如果角色擁有），使角色更具個人特色。

這些工具可由主選單第一頁的 Character Options（角色選項）進入。工具操作方式請參閱
參考卡。
