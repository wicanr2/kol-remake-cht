## 勘誤與停止線

RE-185／187／195 的「其他來源不接續」保留作當時隨機遭遇切片的歷史結論。
新匯出明示正常任務也有自己的世界續行，並設次格 4、4。
因此不能把「保護無關或過期戰鬥」擴大成「所有任務均不得接續」。
修正以實際任務狀態指標識別來源；無關或過期戰鬥仍不得操作其他旅程。

原版正常任務返回的動態成本、完整骰序與勝利搜刮仍待獨立 dosgolem 收據。
本檔的原版結論限於上述靜態控制流，重製版正常路線限於實際驗證範圍。
