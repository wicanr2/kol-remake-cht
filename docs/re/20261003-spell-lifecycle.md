# RE-208：法術啟用旗標與倒數生命週期

日期：2026-10-03。實作前證據審查通過，現為局部有限 CONFORMED。
本輪工作區為 `workplace/spell-lifecycle-20261003/`，由本頁索引。

原版輸入沿用 `KOLTOWN-unpacked.EXE` 與固定 IDA Pro 9.4 資料庫。
EXE SHA-256 `01f6f9a95c4adf8e9da59fa83bae57aa282e5576767b41bfc2f23302aeb9d1d2`，
DB SHA-256 `5c32c977bd420c3a51e5c068ece78f830c4f252445cf138623fbaba64fe551c8`。
位址空間為 IDA 線性；DS 偏移另標示，DGROUP 基底 `0x2DED0`。

本輪問題是成功施放疲勞法術後的舊法術啟用狀態，以及正常回合結算的失效時機。
原版 `+0x0D` 是啟用旗標，`+0x30` 才是倒數。RE-207 的局部夾具在 `+0x0D` 寫入 5，
只能驗證非零旗標被清除，不能當作倒數 5 被清除的原始 byte 證據。
這是對前批證據定位的追加勘誤；不覆寫前批收據。

既有來源指出 `sub_2198A`／`sub_2215A` 不還原攻防技能罰值，正式碼已保持此規則。
此部分不因名稱或註解重新開啟實作。
1,313 道原始指令 bytes 與 21 個固定 seed 1 的 dosgolem 局部案例已審查通過。
有效倒數映射、疲勞法術取消與倒數先於勝負／逃跑的順序達到實作證據要求。
本輪不追合法法術資料與正常玩家路徑不會用到的硬體、亂數或 malformed 記錄邊界。

前批 [RE-207](20261003-spell-reactions.md) 的 3959 份附件與共用輸入先封存，維持原本驗收範圍。
怪物四套資料格式與繁中注解版面仍待原有選擇。

## 舊碼反例與驗證環境

乾淨舊碼反例有 10 個失敗子案例：疲勞法術正負各一、一般回合／逃跑／勝利出口、
力竭後失效，以及雙語各兩個 UI 出口。其餘 19 個原版局部案例通過。
第一批夾具漏帶來源 `Hurt=11`，造成額外比較失敗；這是夾具問題，
修正初始欄位後以同一命令乾淨重跑。第一批 log 留在 `baseline-fixture-mismatch.log`。

工具為 IDA Pro 9.4、dosgolem 上述固定 revision、Go 1.26.7／Ebitengine 2.9.9。
本輪不建新 image；全部工作使用既有 image、UID/GID 1000:1000 與有界 Docker 容器。
