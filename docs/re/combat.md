# 戰鬥

這份導覽整理現行戰鬥實作與證據入口。行為契約在
[SPEC-008](../spec/008-combat-field.md)、[009](../spec/009-combat-attack.md)、
[010](../spec/010-combat-commands.md)，數字與逐條反組譯在 RESEARCH-LOG。

## 一場戰鬥的形狀

```
進入            → 任務地點（sub_2B0FF）或野外遭遇（sub_2A4E5）
遭遇畫面        → 滿版怪物圖 ＋ 記錄 0xE9／0xE7
戰場            → 9×9 視窗、視線、參戰者
  ┌ 規劃段 ────────────────────────────┐
  │ 每個參戰者依序決定這一回合要做什麼      │
  │ 隊員：指令列 → 目標 → 子選單           │
  │ 敵人：sub_2374C 決定                  │
  └───────────────────────────────────┘
  ┌ 執行段 ────────────────────────────┐
  │ 依「快捷值」排序，一手一手做出來        │
  │ 每一手印一句訊息，等玩家按一次鍵        │
  └───────────────────────────────────┘
                → 勝利／落敗／逃離 → 報酬或搜刮 → 傷勢與物品回寫
```

## 幾個容易踩的地方

規劃段先讓每個參戰者各自決定，執行段才依快捷值
重排順序做出來。所以決定的順序與執行的順序不同（RE-080）。

移動方式會影響總格數。WALK 一格、RUN 一格、SPRINT 兩格；魔法鞋與飛行另有規則。
早期 RE-085 只看到主迴圈的一格，後續 RE-154 補齊第二輪移動，見 SPEC-010 的總格數表。

**兩處子選單容易標反。**`0x1F6BA`（0x2A…0x2E）是**武器**攻擊式、`0x1F940`
（0x37…0x3A）是**徒手**。三個判準：分派表、`[0x0FD2]` 只有六筆、`[0x110A]` 的九列。

**一場戰鬥的敵人只有一種。**`sub_2687F` 印敵人名字時**不帶索引**，固定讀
DGROUP+0xB967 那一份，所以同一場所有敵人共用一個名字（RE-090）。

移動訊息與重畫有各自的可見性閘門。可見的成功移動會先印訊息並等鍵，再更新視窗並等鍵；
不能把所有移動固定成兩個等待點。現行接線與正常證據見
[RE-290](20261006-move-message-visibility.md)，長任務回歸見
[RE-291](20261006-visibility-current-regression.md)。

**訊息整段轉成大寫，白底黑字，底圖是 MISCPICS 圖 1 的卷軸。**執行段一開始就把
(8,164) 起 296×32 那一整條換掉，指令圖示列被蓋住（RE-089、090）。
