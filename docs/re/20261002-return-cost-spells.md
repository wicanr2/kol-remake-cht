來自讀值，沒有來自新增擲骰。其餘表外byte只記原始位移與實測值，不猜補語意。

## 勘誤與下一閘門

RE-188保存的18個byte只足以驗已觀察的−1..16，不能代表所有戰後索引。
0x20BAA的負重乘數不是施法收尾的最後寫入。這項勘誤保留RE-188原始證據與收據。

尚未證實正常施法後返回時是否保留上述值。後續須先確認玩家可達的法術、最後
收尾角色、逃走／搜刮等後續寫入及天候更新後真正讀取值，再審查正式成本追蹤。
不能只加18byte表、按勝敗固定成本、將表外夾為方向或以單一靜態記憶體快照冒充
所有執行狀態。父SPEC-011／027及第6／44項保持開放。

首次實驗直接呼叫整支sub_297F2，未正常返回，未產生成本驗證結果。該輸入只有_main
初始化，未分類為原版或產品缺陷。首版來源、腳本及失敗log均保留；第二版只驗
已明示的指令切片，沒有宣稱整支步行常式完成。
