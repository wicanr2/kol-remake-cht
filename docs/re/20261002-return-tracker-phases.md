## 已證實的索引與寫入

| 定位 | 原始指令／bytes | 本場結果 |
|---|---|---|
| `0x1FD90..1FD9A` | `imul word_2FB4A`、`idiv cx`、`mov word_39A54,ax`；最後bytes `a384bb` | 快捷乘疲勞比例再除200；使用SS:BP-2人物索引 |
| `0x1FE3A..1FE50` | 原指令查`[bx+10B2h]`，選項1折半，寫BB84 | 固定指令成本或查表成本；沒有按勝負固定值 |
| `0x20227..20231` | `imul word_37D2A`、`add ax,30h`、`mov word_39A54,ax`；bytes `a384bb` | 一般丟棄留下人物手持欄位移；Warder索引1留下`0x330`，即816 |
| `0x26A62..26A65` | `mov ax,[bp+var_2]`、`mov word_39A54,ax`；bytes `a384bb` | 強制掉落留下地面格號；本場格1。人物參數讀SS:BP+6，不拿局部格號當人物 |
| `0x21045` | `mov word_39A54,0`，bytes `c70684bb0000` | 清零前觀察不當作已執行寫入；以`0x2104B`核對清零後結果 |
| `0x21801..21821` | 原始清槽迴圈逐byte清16格，BB84由0加至16 | 本場五次清槽，共85個迴圈比較點，最後留下16 |

126個快捷折算點的全域人物索引都與SS:BP-2不同。沿用全域索引時，94個算值
與原版不符，例如第3回合Warder應留下12，錯取Olear會得到0。這是觀察索引的
反例，不是原版或正式規則缺陷。

一般丟棄與強制掉落不能共用同一暫存寫入。早先「成功掉落」的分類不足以描述
兩條路徑；本輪以原始指令及正常816／1觀察補上差異，舊來源與收據保留。
