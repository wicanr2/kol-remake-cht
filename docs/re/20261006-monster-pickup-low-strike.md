## 執行與完成界線

原版由既有 dosgolem 固定來源版本啟動，正常招募、出城、旅行至任務 5，接受後按原版選單操作。觀察 hooks 唯讀。只允許招募前兩個亂數種子 word 的一次寫入。保留每個按鍵的完整角色、怪物、地上物品、座標、亂數、事件與畫面。

成功拾取必須由完整 16 bytes 的地上物品搬入怪物手持欄，並核對地上空槽標記及座標處置。空槽以第 0 byte 為零判定，見 SPEC-010；其餘原始 bytes 與座標另存，不能預設全部清零。仍在戰鬥或沒有成功拾取時保留有界結果，不宣稱整場 AI、存檔或原版 parity 已完成。
