# RE-295：正常購馬保存後的野外騎走路徑

日期：2026-10-06。狀態：出城移動率子切片有限 CONFORMED；自然騎走與紮營操作仍開放。

接續 [RE-293](20261006-steed-trade-normal.md) 真正保存的馱馬角色，正常啟動、選角、
離店與出城，再固定有限步行鍵。使用者尚未選定的馬廄確認原型不參與本輪。
工作區為`workplace/rideaway-normal-20261006/`，入口為同區`plan.json`。

兩側使用seed1；原版在正常旅店招呼後、第一個延伸鍵前只設定一次，重製在正常啟動前
設定。原版的四個真正保存檔唯讀複製到本輪scratch，沒有修改角色或注入座標／遭遇。
若第一個遭遇提示已出現，以同一固定前綴回放YES與確認鍵。無提示則在既定上限停止，
不延長同場、重播種或挑有利結果。最長200個原版延伸鍵，程序540秒。

既有原版觀察二進位的`reload`欄位只表示是否跳過播種；本輪保留false以固定測試seed，
真正重載的來源、四檔雜湊及複製方式由本輪`plan.json`與各case的`process-plan.json`記錄。
不把該舊欄位解讀為沒有載入保存檔。尚未完成前不稱正常騎走或完整野外對拍通過。

## 初次正常路徑與移動率原型

原版固定169延伸鍵、170觀察狀態退出0，程序189.914秒；四個真正保存檔未改，
沒有DOS寫檔，沒有未實作指令。原版止於紮營畫面，本上限內尚未取得自然騎走問答。
現行正式／唯讀觀察雙語各188狀態，卻在第140步出現騎走問答，不能當作同旅程對拍。

現行出城回呼只更新世界位置，`partyMovement`在正常角色清單選角以前初始化，
沒有在出城時依實際隊伍刷新。原角色資料頁、完整16-byte馱馬記錄與保存均為移動率10；
早期空隊伍的移動率會以20扣時刻，騎走資格卻依另一個0值判斷，兩條使用失配。
隔離原型只在出城回呼先依實際隊伍更新Movement；原型與前版唯讀觀察另記移動率，
正常玩家鍵序、真正保存、seed1與最長200鍵不變。此階段原型不進正式來源。

本輪工作區的plan.json、各case command.json及process-plan.json記錄實際鍵序、保存來源、
播種與上限。run-native.py是169鍵原版有界試驗；run-remake.py、run-prototype.py保存初次與

中立、保存回歸及僅一行來源差分，既有收據不回寫。
