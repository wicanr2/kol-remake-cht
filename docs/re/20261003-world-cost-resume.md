## READY審查與正式修改

只接既有已證實讀值。普通步行保留FFFF／0／1索引，實際隨機戰鬥共同出口以
搜刮後ReturnScratch覆寫。天候骰完成後，讀當時索引、移動率及亂數State再算成本。
不按勝負重建，不夾索引，不增加骰數，不改保存格式。

| 讀值 | 等級與範圍 |
|---|---|
| FFFF → 表前byte0 | 已證實，原版北向及RE-189切片 |
| 0..7 → 八地形byte | 已證實，RE-188資料錨與既有地形表 |
| 8..19 → 十二月天數 | 已證實的既有日曆資料；正常返回16讀九月30 |
| 840..843 → 當時32-bit seed小端序byte | 既有32-bit亂數狀態與RE-193動態窗；RE-189只直接抽測840，seed1／2成本42／44 |
| 其他索引 | 未實作；EGA畫面等別名尚未映射，不能取初態或常數猜補 |

讀取器對未知別名或無State的亂數來源回報未解決。Session保存診斷，正式共同出口
輸出索引；該分支沿既有方向近似，仍是忠實度缺口。這不將近似升格為原版規則。
普通步行完成後清掉待處理索引，換日接續沒有步行索引，其他來源及重複出口不扣時刻。

本批改`internal/world/session.go`、`cmd/kol/main.go`與共同出口測試，新增
`internal/world/return_cost.go`及測試。318份正式碼輸入保存雜湊；戰鬥寫入碼不變。
