# RE-229：圖片與操作畫面 HD 清冊及方向樣張

日期：2026-10-04至05。狀態：手繪媒材已選，版面及素材尚未定版。

使用者要求安排遊戲圖片，包括操作畫面的 HD 化。工作清單為 hd-art-ui。
本輪先從現行素材 manifest 及正常玩家路徑確認母體，再比較視覺方向。
使用者已確認採用HD手繪重繪。此決定只涉及媒材；目標解析度、人物造型與介面
仍需確認。方向原型不接正式遊戲，也不是已核准構圖。

工作區為 workplace/hd-art-ui-20261004/。prepare.py 檢查現行 Go 來源、素材雜湊與
PNG 格式，建立 inventory.json；replay.sh／replay.py 從正常標題按鍵走到城鎮及戰鬥，
以相同 seed 及初始狀態與 RE-225 軌跡核對。畫格只作 HD 原型來源，不宣稱新原版 parity。

清冊區分顯示圖片、圖集、地圖索引與渲染資料。資料 PNG 不作美術重繪。
角色身體、裝備及怪物透明貼圖，動畫的圖片順序與版面座標均要另驗，整頁樣張不能代替。

決策樹依序為視覺方向、目標解析度及版面、素材規格、逐組實作及正常玩家驗收。
先比較 HD 像素重繪與 HD 手繪方向，使用者選擇手繪媒材。操作名稱、數值、物件數量、
城鎮與戰場格子位置用原型來源核對，生成圖的變動明列，不能當作正式規則或可點擊介面。

比較入口為[離線頁](../../docs/verification/local/workspace-cleanup-20261024/browse/workplace/hd-art-ui-20261004/review.html)。內建image_gen提示保存在
prompts.json及painted-revision-prompt.txt，原始生成圖未改尺寸。review.py驗PNG標頭、CRC及資源入口，
prototype-review.json記錄圖像來源、尺寸與差異。手繪初版媒材不足，保留為迭代記錄。

## 目前前沿：解析度與版面

比較入口為[比例及版面原型](../../docs/verification/local/workspace-cleanup-20261024/browse/workplace/hd-art-ui-20261004/layout-review.html)。
layout-review.html以正常來源PNG作SVG介面原型，沒有重繪或覆寫來源PNG。

| 選項 | 原型行為 | 代價 |
|---|---|---|
| 1920×1200，16:10 | 全部區域保持同比例；1920×1080顯示器置中為1728×1080，左右各96留邊 | 畫面無裁切，不能填滿16:9顯示器 |
| 1920×1080，16:9 | 側欄、主視野及操作列分別同比例縮放並重排 | 填滿16:9；字級、留白及命中區需要新的契約與驗收 |

16:9原型只示範區域重排，不增加可見地圖、不拉伸戰場格子，也不驗證文字最長字串。
SVG區域以正常960×600畫格的取樣矩形為原型來源，沒有宣稱已接正式唯一幾何。
縮放、座標轉換與原型邊界由layout-geometry.json記錄；正式命中區及中文安全矩形
須在使用者選定版面後查既有座標來源。兩案保留手繪方向決定，畫面內容仍用現行PNG，
避免把生成圖的編號或人物差異當作正式版面依據。

原型檔案及座標核對入口review_layout.py；瀏覽器操作與遊戲整合尚未驗證。
決策記錄見decision.json。現階段不改正式素材、資料格式、人物保存v3、版號或交付包。

inventory.json與prototype-review.json保留製作時的「style undecided」狀態，最新決策由
decision.json記錄。封存入口同工作區seal.py／verify.py；receipt.json綁定附件及靜態
程式、素材、來源回放輸入，文件另以documents/快照保存，不綁定後續會更新的全域文件。
